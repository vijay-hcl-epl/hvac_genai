# 1.0 System Overview
The HVAC flap actuator system is a microcontroller-based prototype intended to demonstrate software process compliance and functional behavior for controlling airflow direction or mixing in automotive applications. The system consists of a DC motor-driven flap whose position is monitored by a potentiometer. The position is selectable by user command through UART, and feedback/status is provided by indicator LEDs. The primary goals are learning and process demonstration, not production deployment.

# 2.0 Flap Position Control Requirements
SYS-REQ-001: The system shall allow the user to command a discrete flap position in the supported range via UART.
SYS-REQ-002: The system shall compare the current flap position, determined by potentiometer feedback, to the commanded target position.
SYS-REQ-003: The system shall actuate the motor to move the flap from its current position toward the target position upon command.
SYS-REQ-004: The system shall stop the motor when the current position matches the commanded target position.
SYS-REQ-005: The system shall maintain the flap in the target position until a new valid command is received.
SYS-REQ-006: The system shall support exactly six flap positions mapped to logical indices (0–5) unless explicitly reconfigured.
SYS-REQ-007: [Implied] The system shall continuously or periodically monitor current flap position during operation to detect when target is achieved.

# 3.0 Motor Control Requirements
SYS-REQ-008: The system shall control the direction of the DC motor using two dedicated GPIO pins.
SYS-REQ-009: The system shall enable and disable motor power using a dedicated motor enable signal (PWM or GPIO).
SYS-REQ-010: The system shall stop the motor promptly when the commanded target position is reached.
SYS-REQ-011: [Implied] The system shall stop the motor if an out-of-range feedback value is detected on the potentiometer/ADC.
SYS-REQ-012: [Implied] The system shall ensure that only one motor direction is active at any given time to avoid H-bridge short conditions.

# 4.0 Position Feedback Acquisition and Processing
SYS-REQ-013: The system shall use a rotary potentiometer mechanically linked to the flap to sense current position.
SYS-REQ-014: The system shall connect the potentiometer output to an ADC input channel on the microcontroller.
SYS-REQ-015: The system shall map the measured ADC values into defined discrete flap positions (0–5) by fixed software thresholds.
SYS-REQ-016: [Implied] The system shall treat any ADC value outside of calibration range as invalid and take safe action (stop motor, ignore movement command).

# 5.0 User Command Interface Requirements
SYS-REQ-017: The system shall accept numeric single-digit UART commands from the user to select a target flap position (0–5).
SYS-REQ-018: The system shall ignore any received UART command outside the supported range (0–5) without sending an error or acknowledgment.
SYS-REQ-019: The system shall validate each incoming UART command for numeric integrity before processing.
SYS-REQ-020: [Implied] The system shall accept only one user command at a time; concurrent commands are not supported.

# 6.0 Status Indication Requirements
SYS-REQ-021: The system shall indicate its power-on state using a dedicated status LED.
SYS-REQ-022: The system shall indicate the current flap position using up to six dedicated green LEDs, one for each position.
SYS-REQ-023: The system shall ensure that only one position LED is lit at any time to display the current logical flap position.
SYS-REQ-024: [Implied] Status and position indication LEDs shall be driven by GPIO outputs under microcontroller control.

# 7.0 System Behavioral Requirements
SYS-REQ-025: The system shall initialize all I/O peripherals (UART, ADC, GPIO, PWM) on power-up.
SYS-REQ-026: The system shall ensure the motor is off at power-up and during initialization.
SYS-REQ-027: The system shall read the potentiometer on power-up and update the position indication accordingly.
SYS-REQ-028: Upon receiving a valid position command, the system shall move the flap to the commanded target and stop once achieved.
SYS-REQ-029: The system shall remain idle (except for monitoring for UART commands) if no new command is received.
SYS-REQ-030: The system shall safely ignore invalid UART commands and invalid ADC feedback without system fault.
SYS-REQ-031: [Implied] The system shall not attempt to move the flap unless a new valid target different from the current position is commanded.
SYS-REQ-032: [Implied] If the motor fails to move the flap to target, the system shall not lock up or crash (best-effort movement only).

# 8.0 System Interface Requirements
SYS-REQ-033: The system shall use the UART interface to receive user commands from a PC or laptop via USB/UART converter.
SYS-REQ-034: The system shall use GPIO outputs to control direction and enable signals for the motor driver (L298N).
SYS-REQ-035: The system shall acquire position feedback from the potentiometer via an ADC input.
SYS-REQ-036: The system shall use GPIO outputs to drive each status and position LED.

# 9.0 Constraints and Assumptions

- All complexity is contained and visible to aid in learning and traceability.
