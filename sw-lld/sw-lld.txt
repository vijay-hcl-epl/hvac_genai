SW UNIT: UART/LIN DRIVER (HAL)
====================
1. Responsibilities
   - Handles initialization and operation of UART1/LIN and UART2 modules for serial RX/TX (per sw-arch).
   - Does not handle protocol decoding at application level.
2. Internal Data Design
   - Variables: RX/TX buffer (static), error flag/status, config struct with mode/baud/enable; LIN status field. All statically allocated.
   - Config fields: Mode select, baud rate, break config (LIN), interrupt enables.
3. State Machine
   - State: None. Operates as event-driven I/O.
4. Algorithms & Control Flow
   - (Pseudocode):
     - On init:
         - Set UART1_CON.M (mode)
         - Set UART1_CON.TEN/REN (enable TX/RX)
         - Set UART1_BRG (baud)
         - For LIN: LINCON.EN, LINCON.break config; clear LINSTAT
     - On send:
         - Write data to UARTx_TXD
         - For LIN, use HW break/synch
     - On receive:
         - Read from UARTx_RXD, set flag/IRQ
     - On error:
         - Read LINSTAT/UARTx status; set error code
5. Interfaces (APIs)
   - Provided: Serial_tx(data*), Serial_rx(ptr*), Serial_init(cfg), Serial_status()
   - Required: Access register fields
   - Params: Data ptr, config ptr; Returns: status code, error
6. Error Handling
   - Detect framing, parity, overrun errors via LINSTAT, UARTx; set error flag
7. Resource & Timing Considerations
   - Non-reentrant; RX/TX via HW events/interrupt only; WCET bounded by HW data register access
8. Traceability
   - SWE-REQ-017, SWE-REQ-018, (interface)

SW UNIT: ADC DRIVER (HAL)
====================
1. Responsibilities
   - Handles setup, single conversion, and readout of potentiometer input via ADC1 for flap position; reports conversion complete/invalid
2. Internal Data Design
   - Static latest value, static config struct (resolution, channel selection, enable)
3. State Machine
   - None; single-shot or event-driven
4. Algorithms & Control Flow
   - On init:
         - Set ADC1_CHSEL (input pin)
         - Set ADC1_CON.RES (resolution)
         - ADC1_CON.ADEN (enable)
     - Start conversion: Set ADC1_CON.START
     - Wait for: ADC1_IS (conversion done)
     - Read result: ADC1_RES
5. Interfaces (APIs)
   - Provided: ADC_init(cfg), ADC_start(chan), ADC_result(), ADC_status()
   - Required: Register field access
   - Params: Config ptr, channel
   - Returns: Status, result (uint16)
6. Error Handling
   - Out-of-range flag, timeout on conversion; status code
7. Resource & Timing Considerations
   - Not reentrant; WCET = conv_time + reg access; call only from control logic
8. Traceability
   - SWE-REQ-020, SWE-REQ-012

SW UNIT: MOTOR DRIVER (HAL)
====================
1. Responsibilities
   - Handles PWM setup, direction, and enable on H-bridge outputs (via BDRV, GPT1 timers)
2. Internal Data Design
   - Static config (period, duty, polarity), direction flag, state enum, error code
3. State Machine
   - None, stateless per cmd
4. Algorithms & Control Flow
   - On init:
         - Set GPT1_CON (mode, prescale), GPT1_OC (period/duty)
         - BDRV_CON.EN/dir bits
     - To run motor: PWM start, BDRV enable, direction
     - To stop: Clear enable
     - Update duty/dir as needed
5. Interfaces (APIs)
   - Provided: Motor_init(cfg), Motor_run(dir,spd), Motor_stop(), Motor_status()
   - Required: Register field access
   - Params: Dir enum, speed (duty)
   - Returns: Status code
6. Error Handling
   - Detect BDRV fault/reg, shut down if so; set error flag
7. Resource & Timing Considerations
   - Not reentrant; only one op at a time; call from control
8. Traceability
   - SWE-REQ-019, SWE-REQ-009, SWE-REQ-010

SW UNIT: GPIO/LED/HS DRIVER (HAL)
====================
1. Responsibilities
   - Handles digital output of system state/position via GPIO pins and high-side (HS) drivers
2. Internal Data Design
   - Static config of output pins, state var for current indication
3. State Machine
   - State: None; assignment by event
4. Algorithms & Control Flow
   - On init:
         - Set IOCON (mux)
         - IOCRy.DIR=1 (output)
         - HSx_CON.EN (enable HS out)
     - Set output: IOOUTy (set pin), HSx_CON.EN
     - Readback: IOINy (if needed)
5. Interfaces (APIs)
   - Provided: LED_set(state), HS_set(index,state), GPIO_init(cfg)
   - Required: Register fields
   - Params: State enum/index
   - Returns: status
6. Error Handling
   - Detect and flag HSx_CON fault flag
7. Resource & Timing Considerations
   - Not reentrant, fast op; call only from indication logic
8. Traceability
   - SWE-REQ-021, SWE-REQ-014

SW UNIT: COMMAND INTERPRETER
====================
1. Responsibilities
   - Handles decode and validation of user commands (position set), rejecting out of range or malformed
2. Internal Data Design
   - Static decoded value, flag for valid/range, last cmd
3. State Machine
   - State: None; event-driven
4. Algorithms & Control Flow
   - On receive: validate value (0-5); set valid flag; output to State Manager
5. Interfaces (APIs)
   - Provided: Cmd_decode(data*), Cmd_status()
   - Required: Serial_rx
   - Params: ptr (input)
   - Returns: valid (bool), value
6. Error Handling
   - MALFORM/OUT_OF_RANGE, set invalid flag, ignore
7. Resource & Timing Considerations
   - No resource hold; one cmd at a time
8. Traceability
   - SWE-REQ-001, SWE-REQ-002, SWE-REQ-026

SW UNIT: STATE MANAGER
====================
1. Responsibilities
   - Holds operational state: Idle, Moving, Target_Reached, Fault, Sleep/Stop; handles allowed transitions
2. Internal Data Design
   - Static enum state, prev state, status word, time flag, [TBD—not in source: timer config if needed]
3. State Machine
   - States: {Idle→Moving→TargetReached, Fault, Sleep/Stop}. Transitions per SWE.1
4. Algorithms & Control Flow
   - Update on: new cmd, target match, error/fault, low-power input
   - Switch state, output to handlers
5. Interfaces (APIs)
   - Provided: StateMgr_update(event), StateMgr_status()
   - Required: FlapCtrl, FaultHandler
   - Params: event/cmd struct
   - Returns: cur state enum
6. Error Handling
   - If invalid state/event, set Fault
7. Resource & Timing Considerations
   - Not reentrant, event only
8. Traceability
   - SWE-REQ-025, SWE-REQ-027, SWE-REQ-028, SWE-REQ-031

SW UNIT: FAULT HANDLER
====================
1. Responsibilities
   - Monitors motor, ADC, and system fault indicators; initiates safe shutdown and reporting
2. Internal Data Design
   - Fault status word, last event, flags for each major source
3. State Machine
   - State: None; fault events per event-driven
4. Algorithms & Control Flow
   - On input: check all faults flags; if set, shut down motor, flag status, report
5. Interfaces (APIs)
   - Provided: Fault_check(in), Fault_status()
   - Required: Motor_status, ADC_status
   - Params: status struct
   - Returns: fault flag/struct
6. Error Handling
   - All detected faults propagated to State Manager and status interface
7. Resource & Timing Considerations
   - All by event; no resource hold
8. Traceability
   - SWE-REQ-011, SWE-REQ-030, SWE-REQ-036, SWE-REQ-037, SWE-REQ-038
