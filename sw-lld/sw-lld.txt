# 1.0 Low Level Design (LLD) for HVAC Flap Actuator

## 1.1 CommandHandler
- Responsibilities: Receive and validate UART commands; filter/parse/dispatch flap position commands; provide the Command API; use UART and FlapControlLogic interfaces
- Internal Data: Current command buffer, parsed command structure
- Control Logic: On UART event, parse/validate; ignore unrecognized; dispatch to FlapControlLogic
- State Machine: Idle, Receive, Parse/Validate, Dispatch/Error
- APIs: void CommandHandler_Init(void); void CommandHandler_Process(void); void CommandHandler_OnUartRx(uint8_t byte);
- Error Handling: Call ErrorHandler on parse/validate failure

## 1.2 FlapControlLogic
- Responsibilities: Compare current and target position; decide movement; command MotorDriver; support limits; provide Flap Control API; use PositionFeedback and MotorDriver
- Internal Data: Target position, current position, movement state
- Control Logic: On new command, compare positions; determine direction; start/stop MotorDriver; update StatusIndicator
- State Machine: Idle, Moving, Holding, Error
- APIs: void FlapControlLogic_Init(void); void FlapControlLogic_Process(void); void FlapControlLogic_SetTarget(uint8_t position); void FlapControlLogic_OnPositionUpdate(uint8_t position);
- Error Handling: Call ErrorHandler on position/control fault

## 1.3 PositionFeedback
- Responsibilities: Acquire ADC value; map ADC to logical position; range-check; provide Position API; use ADC
- Internal Data: Last ADC value, mapped logical position
- Control Logic: On ADC sample, map/validate; update FlapControlLogic
- State Machine: Valid, Invalid
- APIs: void PositionFeedback_Init(void); void PositionFeedback_Process(void); uint8_t PositionFeedback_GetPosition(void);
- Error Handling: Call ErrorHandler on ADC range fail

## 1.4 MotorDriver
- Responsibilities: Set GPIO/output for motor control; drive PWM/enable; enforce movement limits; provide Motor Driver API; use GPIO/PWM
- Internal Data: Direction, enable flag, state
- Control Logic: Set outputs to achieve commanded movement/stop
- State Machine: Idle, Running, Error
- APIs: void MotorDriver_Init(void); void MotorDriver_SetMove(int8_t direction); void MotorDriver_Stop(void);
- Error Handling: Call ErrorHandler on illegal state

## 1.5 StatusIndicator
- Responsibilities: Set LED outputs according to state; ensure only one green LED on; provide Status API; use GPIO
- Internal Data: Status LED state, position LED state
- Control Logic: Update LEDs based on flap/system status; mutually-exclusive LEDs
- APIs: void StatusIndicator_Init(void); void StatusIndicator_SetStatus(uint8_t status); void StatusIndicator_SetPositionLed(uint8_t position);
- Error Handling: Indicate error status, if required

## 1.6 ErrorHandler
- Responsibilities: Handle invalid commands, ADC or motor errors, fallback
- Internal Data: Error status code
- Control Logic: Set global/system error; notify units as needed (callback or status flag)
- APIs: void ErrorHandler_Init(void); void ErrorHandler_Report(uint8_t errorCode);
- Error Handling: Central point for error status assignment and reporting

## 1.7 UART
- Responsibilities: Abstract UART HW; pass RX byte event to CommandHandler
- Internal Data: In-progress RX buffer
- APIs: void UART_Init(void); void UART_Process(void); void UART_SendResponse(uint8_t* data, uint8_t len); IRQ/event: UART_Receive_ISR(void)
- Error Handling: Call ErrorHandler if hardware fault

## 1.8 ADC
- Responsibilities: Abstract ADC HW; provide sampled values
- Internal Data: Buffer for samples
- APIs: void ADC_Init(void); void ADC_Process(void); uint16_t ADC_GetValue(void);
- Error Handling: Call ErrorHandler if hardware fault

## 1.9 GPIO
- Responsibilities: Abstract GPIO HW; provide set/clear for required pins
- APIs: void GPIO_Init(void); void GPIO_Set(uint8_t pin); void GPIO_Clear(uint8_t pin);
- Error Handling: Call ErrorHandler if hardware fault
