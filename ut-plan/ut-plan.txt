## 2. Unit-Wise Test Cases

### 2.1 UserCmdHandler
- **Responsibility**: Handles UART user commands, validates 0-5, rejects invalid, sends target to FlapCtrl.
- **Allocated SW-REQs**: SWE-REQ-001, SWE-REQ-002, SWE-REQ-003, SWE-REQ-004, SWE-REQ-019, SWE-REQ-034

| Test Case ID    | SW-REQ | Objective                                | Preconditions    | Input  | Expected Result                   | Pass/Fail                    |
|-----------------|--------|------------------------------------------|------------------|--------|-----------------------------------|------------------------------|
| UCH-TC-01       | 001,019| Accept command 0-5, pass to FlapCtrl     | Initialized      | 2      | FlapCtrl called, value 2          | Function called, input valid |
| UCH-TC-02       | 003,004,028,034 | Ignore invalid command (<0 or >5)  | Initialized      | 6      | FlapCtrl NOT called, ignored      | No call/side effect          |
| UCH-TC-03       | 002    | Test all valid positions                 | Initialized      | 0-5    | Each triggers FlapCtrl call       | All valid mapped             |

**Isolation**: Mock UART, FlapCtrl. No UART/ISR/RTOS present. Only value injection, observe calls.

## 4. Example Unit Test Stub (C, Mocked APIs)

```c
#include "UserCmdHandler.h"
#include "mock_FlapCtrl.h"
#include <assert.h>

void test_UserCmdHandler_OnUartRx_valid(void) {
    mock_FlapCtrl_expect_NewTargetCmd(2); // expect call with 2
    UserCmdHandler_OnUartRx(2);           // invoke with valid value
    mock_FlapCtrl_verify();
}

void test_UserCmdHandler_OnUartRx_invalid(void) {
    UserCmdHandler_OnUartRx(99); // Out of range; should NOT call FlapCtrl
    mock_FlapCtrl_verify();       // No calls expected
}
```

**All tests mock MCU/peripheral interfaces and verify call outcomes, never real hardware.**
