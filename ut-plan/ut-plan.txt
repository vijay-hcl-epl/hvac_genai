====================
ASPICE SWE.4 Unit Test Plan
====================

Scope:
Covers unit testing for HVAC flap actuator software, as designed in sw-reqs/sw-reqs.txt, sw-lld/sw-lld.txt, and codegen/code_bundle.txt (branch soft-142a).

Isolation Rules:
- All hardware (ADC, GPIO, PWM, UART) shall be mocked.
- No integration tests, only functional units.
- All tests must be deterministic and repeatable.

----------------------------------------
Software Units (with Responsibilities)
----------------------------------------

1. Startup/Initialization Sequencer
   - Handles hardware/config init at power-up. APIs: Startup_Sequence(void)
2. UART Command Handler
   - UART RX, command decode/validation/forwarding. APIs: UART_Handler_RxISR, UART_GetCommand
3. Flap Position Controller
   - Command/action flow, invokes motor, halts on error/target. APIs: Flap_Ctrl_Tick
4. Motor Driver
   - GPIO/PWM motor control. APIs: Motor_Drive_Set, Motor_Drive_Stop
5. ADC Feedback Handler
   - ADC, position mapping, out-of-range detect. APIs: ADCFbk_GetPosition
6. LED Status Indicator
   - Power/position/error LED control. APIs: LED_SetStatus, LED_SetPowerOn, LED_SetError

Preconditions: UART mock RX provides valid value
Input: UART_Handler_RxISR() with rx = 2
