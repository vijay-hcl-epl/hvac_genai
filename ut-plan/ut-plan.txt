2. TEST STRATEGY & ISOLATION RULES
- All tests shall be executed in isolation (unit context only), no integration with real hardware.
- Adapters/mocks for: ADC, GPIO, PWM, UART.
- All test logic must be deterministic and repeatable.
- Fault and boundary conditions injected via mocks.

3. DETAILED UNIT TEST CASES

# Format for Each Software Unit (examples shown for a subset)

## 3.1 User Command IF
Responsibilities:
- Parse & validate user flap commands, ACK/NACK responses, error on invalid, forward validated command, track command errors.
Allocated SW-REQ: SWE-REQ-001, 002, 003, 019, 020, 021

| Test Case ID   | SW-REQ     | Test Objective                             | Preconditions                      | Input             | Expected Result                              | Pass/Fail Criteria                |
|---------------|------------|--------------------------------------------|-------------------------------------|-------------------|----------------------------------------------|------------------------------------|
| UCIF-NOM-001  | 001, 002   | Accept valid command 0                     | No prior command, initialized       | cmd_value=0       | CommandReceived(0) accepted, status OK       | status_code==0 && pos==0          |
| UCIF-BOUND-001| 003        | Reject command above valid limit           | Initialized                         | cmd_value=6       | ErrorAck() called, SetError(0x01)            | error_count++, status_code==1      |
| UCIF-ERR-001  | 003        | Handle malformed packet                    | Initialized                         | bad framing/parity| ErrorAck(), error_count++, no chip reset     | error_count incremented            |
| UCIF-SEP-001  | 001, 019   | Validate error reporting on UART reception | Initialized, prior error cleared    | invalid command   | SetError() called, status set to error       | error_flags latched                |

## 3.2 Flap Control Logic
Responsibilities:
- Interpret and execute flap position requests, safe state entry, error monitoring.
Allocated SW-REQ: SWE-REQ-005, 006, 007, 010, 011, 013, 014, 022–026, 031

| Test Case ID     | SW-REQ  | Test Objective                 | Preconditions            | Input                  | Expected Result                                | Pass/Fail Criteria             |
|------------------|---------|--------------------------------|-------------------------|------------------------|------------------------------------------------|-------------------------------|
| FCL-NOM-001      | 005     | Move to valid target           | state=IDLE, valid pos   | FlapMoveTo(3)          | state==FLAP_MOVING, MotorDrive called FWD/REV  | pos_target==3                  |
| FCL-BOUND-001    | 006     | Exceed actuator limits         | Initialized             | FlapMoveTo(6)          | ErrorHandler invoked, state==SAFE              | state==FLAP_SAFE               |
| FCL-ERR-001      | 010,014 | Fault during movement          | Moving, ADC fault sim   | ADCGetPos() OOR        | FlapErrorEvent, state==SAFE, MotorOff          | error_flags latched             |

## 3.3 ADC Interface
Responsibilities:
- Scale/calibrate raw ADC, check thresholds, error if out of thresholds.
Allocated SW-REQ: SWE-REQ-005, 007, 012, 013, 014, 022, 023, 024, 025, 029, 031, 040

| Test Case ID   | SW-REQ | Test Objective              | Preconditions | Input             | Expected Result                  | Pass/Fail Criteria         |
|---------------|--------|-----------------------------|---------------|-------------------|----------------------------------|----------------------------|
| ADC-NOM-001   | 012    | Acquire typical position    | ADC ready     | Normal ADC val    | Correct pos decoded, no error    | ADCGetPos() == expected    |
| ADC-BOUND-001 | 014    | Out-of-range value          | Initialized   | ADC above max     | SetError(0x08), return 5         | Error handler triggered    |
| ADC-ERR-001   | 014    | Hardware conversion error   | ADC busy      | Sim timeout      | Error reported, safe state       | Conversion retry/Abort     |
