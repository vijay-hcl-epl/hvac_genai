ASPICE SWE.4 UNIT TEST PLAN
==========================

SW Units Under Test:
--------------------
1. Command Interface
2. Position Feedback Processing
3. Flap Movement/Motor Control
4. Status Indication
5. Control Logic
6. Calibration Data Handler
7. Error Handler

Test Scope and Isolation:
------------------------
- All tests use mocks for ADC, UART, GPIO, PWM.
- No real hardware; all dependencies mocked/stubbed.

Test Case Table: (example excerpt for two units)
-----------------------------------------------

Unit: Command Interface
Responsibility: Handle UART parsing, validation, single command in flight
Allocated SW-REQs: SWE-REQ-001, -002, -003, -016, -031

| TC ID        | SW-REQ      | Objective                                    | Precondition             | Input            | Expected Result                  | Pass/Fail Criteria                 |
|--------------|-------------|-----------------------------------------------|--------------------------|------------------|----------------------------------|------------------------------------|
| CI_TC_01     | 001,016     | Accept valid UART position command            | Idle state               | UART byte '3'    | Returns CMD_OK; drives ControlLogic | CMD_OK, control function called    |
| CI_TC_02     | 002,016     | Reject out-of-range position                  | Idle state               | UART byte '9'    | Returns CMD_INVALID               | CMD_INVALID                        |
| CI_TC_03     | 003,016     | Ignore command if busy                        | command_in_progress=true | UART byte '1'    | Returns CMD_BUSY                  | CMD_BUSY, no state change          |
| CI_TC_04     | 031         | Safe state after invalid command              | Idle                     | buffer overflow  | Command ignored; states unchanged | No exception, safe state held      |

Unit: Position Feedback Processing
Responsibility: ADC acquisition, position calculation, broadcast position
Allocated SW-REQs: SWE-REQ-010, -011, -012, -018, -027, -030

| TC ID        | SW-REQ      | Objective                                          | Precondition               | Input        | Expected Result                  | Pass/Fail Criteria             |
|--------------|-------------|-----------------------------------------------------|----------------------------|--------------|----------------------------------|-------------------------------|
| PF_TC_01     | 010,018     | Sample ADC, provide correct position output         | Valid calibration/init     | ADC=1200     | Logical position=1                | Output=1                      |
| PF_TC_02     | 027         | ADC mapped to logical using calibration             | Valid table                | ADC=2800     | Logical position=4                | Output=4                      |
| PF_TC_03     | 030         | Out-of-range triggers error flag                    | Any                        | ADC=5000     | ErrorHandler_SetErrorState called | Error API called              |
| PF_TC_04     | 012         | Operation in idle state maintains last valid pos    | No movement                | -            | State unchanged                   | No unintended state change    |

Mocking Strategy:
-----------------
All hardware interactions (e.g., ADC_Read, UART_Receive, GPIO/PWM) replaced by mocks or stubs.

Example C Unit Test Stub:
-------------------------
#include "command_interface.h"
#include "unity.h"
void test_CommandAcceptsValidInput(void) {
    CommandInterface_Init();
