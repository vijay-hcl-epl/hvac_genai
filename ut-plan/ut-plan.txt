## Unit 1: Command Handler
- **Responsibilities:** UART RX, validate/ignore invalid
- **SW-REQs:** 001, 002, 003, 004, 017, 032
- **Test Cases:**
  - TC-CMD-001 – Valid command accepted (0–5)
  - TC-CMD-002 – Invalid char ignored
  - TC-CMD-003 – Buffer overflow resets state
  - TC-CMD-004 – Error input (framing/parity): no output, ignored

## Unit 2: Position Control
- **Responsibilities:** Track/set position, move logic
- **SW-REQs:** 005, 006, 007, 025, 024, 028, 029, 031
- **Test Cases:**
  - TC-POS-001 – Accept target in range
  - TC-POS-002 – Reject target out of range
  - TC-POS-003 – On valid, drive movement (calls driver)
  - TC-POS-004 – On match, stops and notifies LED
  - TC-POS-005 – Command during busy: rejected

## Unit 3: Motor Driver Interface
- **Responsibilities:** Drive DC Motor, IO/PWM
- **SW-REQs:** 008, 009, 019, 037, 038
- **Test Cases:**
  - TC-MOT-001 – Drive towards higher pos
  - TC-MOT-002 – Drive towards lower pos
  - TC-MOT-003 – Stop disables output
  - TC-MOT-004 – Ignore out-of-range

## Unit 4: ADC Interface
- **Responsibilities:** Sample ADC, map position
- **SW-REQs:** 011, 012, 013, 018, 029, 031
- **Test Cases:**
  - TC-ADC-001 – Valid ADC range, map position
  - TC-ADC-002 – ADC value out of range, flags error

## Unit 5: LED Status Indicator
- **Responsibilities:** LEDs for power, position, error
- **SW-REQs:** 014, 015, 016, 020, 029
- **Test Cases:**
  - TC-LED-001 – Power-on LED pattern
  - TC-LED-002 – Position LED matches position
  - TC-LED-003 – Error pattern if told

## Unit 6: Error Handling
- **Responsibilities:** Fault detect, safe-state
- **SW-REQs:** 013, 026, 027, 032, 033, 034
- **Test Cases:**
  - TC-ERR-001 – Upon error, disables actuators
  - TC-ERR-002 – FAULT prevents movement
  - TC-ERR-003 – No retry/escalation
