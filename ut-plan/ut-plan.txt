UNIT TEST CASES (EXAMPLES)

### Initialization/Startup Unit
- TC_INIT_01: Verify that after system_init(), sys_init_done is true. [SWE-REQ-024,025]
- TC_INIT_02: Check all outputs are OFF before init_complete(). [SWE-REQ-011]
- TC_INIT_03: Simulate failure in feedback; ensure no crash occurs. [SWE-REQ-011]

### Command Input Unit
- TC_CMD_01: Send valid UART cmd in [0..5], get_valid_position returns correct. [SWE-REQ-001,002]
- TC_CMD_02: Send out-of-range UART command, returns CMD_INVALID. [SWE-REQ-003]
- TC_CMD_03: Non-numeric or noise input ignored. [SWE-REQ-003]
- TC_CMD_04: Multiple valid commands, buffer clearing. [SWE-REQ-019]
- TC_CMD_05: No UART input - unit remains idle. [SWE-REQ-004]

### Feedback Acquisition Unit
- TC_FDBK_01: Simulate in-range ADC, map to correct position. [SWE-REQ-012,013]
- TC_FDBK_02: ADC at edge, mapping is deterministic. [SWE-REQ-013]
- TC_FDBK_03: ADC out of range returns POSITION_INVALID. [SWE-REQ-015]
- TC_FDBK_04: ADC input noise/stuck, still safe. [SWE-REQ-033]
- TC_FDBK_05: Static mapping threshold; no change at runtime. [SWE-REQ-030]

### Flap Position Control Unit
- TC_CTRL_01: On valid move, sets target, starts movement. [SWE-REQ-005,006]
- TC_CTRL_02: No action if current==target. [SWE-REQ-006]
- TC_CTRL_03: Invalid cmd no move. [SWE-REQ-028]
- TC_CTRL_04: On move complete, idle state entered. [SWE-REQ-027]
- TC_CTRL_05: If feedback INVALID, motor halts. [SWE-REQ-033]
- TC_CTRL_06: Only one move per command. [SWE-REQ-031]

### Motor Actuation Unit
- TC_MOTOR_01: Command Fwd/Rev, actuate_motor sets correct output. [SWE-REQ-008,021]
- TC_MOTOR_02: Stop_motor de-energizes outputs. [SWE-REQ-009,010,011]
- TC_MOTOR_03: Multiple start/stop calls, no fault. [SWE-REQ-011]
- TC_MOTOR_04: No action if already stopped. [SWE-REQ-010]
- TC_MOTOR_05: Never sets output if not commanded.[SWE-REQ-021]

### Status Indication Unit
- TC_LED_01: At init, power_led_on sets LED correctly. [SWE-REQ-016]
- TC_LED_02: update_status_leds sets only one position-LED ON. [SWE-REQ-017]
- TC_LED_03: If position invalid, all LEDs OFF. [SWE-REQ-018]
- TC_LED_04: Multiple state changes, never >1 LED ON. [SWE-REQ-022]

ISOLATION/MOCKING RULES
- Hardware drivers (UART, ADC, GPIO/PWM) must be mocked/stubbed.
- No access to real hardware; all hardware interaction functions (register reads/writes) simulated/deterministic.
- Tests must not rely on global/static variables except as designed for test.
- No integration: test each source file/unit in isolation.
