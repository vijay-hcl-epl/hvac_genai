--------------------------
Unit: Command Interpreter
--------------------------
Responsibility: Parse UART-received command strings (expecting "0".."5") and forward valid commands for movement. Ignore invalid input. No UART output. SW-REQs: SWE-REQ-001,002,003,027,032

Test Cases:
[CI-TC-001]
SW-REQ: SWE-REQ-001
Objective: Accept valid UART command in range 0-5
Precondition: CommandInterpreter_Init called
Input: "3" (as RX buffer)
Expected: Valid command, *valid_cmd_out==3, return true
Pass: As Expected

[CI-TC-002]
SW-REQ: SWE-REQ-002
Objective: Reject command below valid range
Input: "-1"
Expected: return false, *valid_cmd_out unchanged

[CI-TC-003]
SW-REQ: SWE-REQ-002
Objective: Reject command above range
Input: "7"
Expected: return false

[CI-TC-004]
SW-REQ: SWE-REQ-002
Objective: Reject malformed input
Input: "abc"
Expected: return false

[CI-TC-005]
SW-REQ: SWE-REQ-003,027
Objective: Ignore invalid command (no UART output, no state change)
Input: "x"
Expected: return false, UART not used for response

--------------------------
Unit: Position Controller
--------------------------
Responsibility: Command target moves, poll feedback, orchestrate move and error
SW-REQs: SWE-REQ-004,005,006,024,025,026,028

Test Cases:
[PC-TC-001]
SW-REQ: SWE-REQ-004
Objective: Accept command if != current_pos in range
Pre: PositionController_Init(), FeedbackProcessor return current_pos==2
Input: RequestMove(3)
Expected: pos_state == MOVING, target_pos==3

[PC-TC-002]
SW-REQ: SWE-REQ-005
Objective: Stop at target_pos
Input: Simulate feedback return == target_pos
Expected: Motor stopped, state==IDLE

[PC-TC-003]
SW-REQ: SWE-REQ-006
Objective: Not move until valid command
Input: None post-init
Expected: Motor not started

[PC-TC-004]
SW-REQ: SWE-REQ-026
Objective: Enter error state if out-of-range feedback
Input: Feedback = 0xFF during move
Expected: pos_state==ERROR, Motor stopped

[PC-TC-005]
SW-REQ: SWE-REQ-024
Objective: Allow one cmd at a time
Input: Two back-to-back requests
Expected: Only first accepted (per code logic, see reentrancy)

// Example C stub for CommandInterpreter_Validate
#include "command_interpreter.h"
#include <assert.h>
#include <string.h>
void test_CI_TC_001() {
  char buf[8] = "3";
  uint8_t out = 0xFF;
  bool ret = CommandInterpreter_Validate(buf, &out);
  assert(ret == true && out == 3);
}
void test_CI_TC_004() {
  char buf[8] = "abc";
  uint8_t out = 42;
  bool ret = CommandInterpreter_Validate(buf, &out);
  assert(ret == false && out == 42); // output stays
}
