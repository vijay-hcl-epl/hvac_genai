# ASPICE SWE.4 Unit Test Plan – HVAC Flap Actuator

## 1. Introduction
This plan covers unit-level (software component/module) functional and robustness tests for all units derived from:
- sw-reqs/sw-reqs.txt
- sw-lld/sw-lld.txt
- codegen/code_bundle.txt

### Scope
- No real hardware: all peripheral functions (ADC, GPIO, PWM, UART) are mocked.
- Only unit isolation tests included, no integration.

---

## 2. Software Units Under Test

1. Command Manager
2. Flap Control Coordinator
3. Motor Control
4. Feedback Processing
5. LED Management
6. Hardware Abstraction

---
