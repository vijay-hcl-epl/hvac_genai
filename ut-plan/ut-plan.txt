1. UART Command Handler
2. Position Feedback Handler
3. Flap Motor Actuation Unit

5. Control Logic & State Manager

- SW-REQ(s)

## UART Command Handler
**Responsibilities:** Handles reception/validation of position commands over UART (SWE-REQ-001, SWE-REQ-002, SWE-REQ-003, SWE-REQ-016, SWE-REQ-028)

### Tests
| TC_ID         | SW-REQ(s)        | Objective                                      | Preconditions           | Inputs                   | Expected Result                         |
|---------------|------------------|------------------------------------------------|-------------------------|--------------------------|------------------------------------------|
| UART_TC_001   | SWE-REQ-001      | Accept valid command 0..5                      | Board init; idle        | UART RX '5' + CR         | last_cmd_value=5; ready; returns true    |
| UART_TC_002   | SWE-REQ-002,028  | Ignore out-of-range command                    | Board init; idle        | UART RX '9' + CR         | No change; last_cmd_value=-1; false      |
| UART_TC_003   | SWE-REQ-028      | Ignore non-digit command                       | Board init; idle        | UART RX 'Z' + CR         | No change; last_cmd_value=-1; false      |
| UART_TC_004   | SWE-REQ-001,003  | Only 1 command accepted at a time              | last_cmd_value=set      | UART RX '3' + CR         | Ignore until cleared                     |
| UART_TC_005   | SWE-REQ-002      | Command buffer clears after result is read      | last_cmd_value=valid    | uart_clear_command()     | cmd_ready=false; value=-1                |

Boundary/input fault tests covered: input range, input state, buffer clearing, non-digit detection, etc.

Isolation: All UART RX is mocked (simulate ISR/data callback), no hardware used.

## Example C Unit Test Stub (for UART Command Handler)

#include "unity.h"
#include "uart_command_handler.h"

TEST_CASE(UART_TC_001, "Accepts valid command") {
    uart_rx_handler((void*)"5");
    uart_rx_handler((void*)"\n");
    int cmd;
    TEST_ASSERT_TRUE(uart_get_last_command(&cmd));
    TEST_ASSERT_EQUAL(5, cmd);
}

TEST_CASE(UART_TC_002, "Ignores out-of-range") {
    uart_rx_handler((void*)"9");
    uart_rx_handler((void*)"\n");
    int cmd;
    TEST_ASSERT_FALSE(uart_get_last_command(&cmd));
}
