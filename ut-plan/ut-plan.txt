=====================
ASPICE SWE.4 Unit Test Plan
HVAC Flap Actuator System
=====================

Software Units:
- Command Handler (UART Processor)
- Position Manager
- Flap Control Logic
- Motor Driver Abstraction
- Position Feedback Acquisition
- Status Indicator Controller

------------------------------------------------------------
UNIT: Command Handler (UART Processor)
------------------------------------------------------------
Responsibilities:
  - Handle UART RX for target position commands. Validate input. Dispatch to PositionManager. Reject/busy if already processing or invalid.
  - Implements: SWE-REQ-001, SWE-REQ-002, SWE-REQ-003, SWE-REQ-004, SWE-REQ-017, SWE-REQ-026, SWE-REQ-032
APIs: validate_and_dispatch(uint8_t cmd)

Test Cases:
TC-CMDH-001 | SWE-REQ-001 | Accept and dispatch valid command | Handler idle, valid cmd | cmd=2 | CMD_ACCEPTED | Validate: status==CMD_ACCEPTED
TC-CMDH-002 | SWE-REQ-002 | Reject invalid range command      | Handler idle, invalid (cmd=9) | cmd=9 | CMD_IGNORED | status==CMD_IGNORED
TC-CMDH-003 | SWE-REQ-003 | Reject if busy                    | Handler busy | cmd=3 | CMD_BUSY | status==CMD_BUSY
TC-CMDH-004 | SWE-REQ-026 | Ignore invalid, system not changed| Handler idle | cmd=20 | CMD_IGNORED | status==CMD_IGNORED, no call PositionManager
TC-CMDH-005 | SWE-REQ-032 | Silently ignore                 | Handler idle | cmd=150 | CMD_IGNORED | status==CMD_IGNORED

------------------------------------------------------------
UNIT: Position Manager
------------------------------------------------------------
Responsibilities:
  - Validate position, track actual/target, block when busy, coordinate move sequence.
  - Implements: SWE-REQ-003, SWE-REQ-012, SWE-REQ-013, SWE-REQ-014, SWE-REQ-028
APIs: PositionManager_command(uint8_t pos), get_CurrentPosition(void)

Test Cases:
TC-POSMGR-001 | SWE-REQ-013 | Accepts valid in-range position           | Not busy | pos=4 | POSMGR_ACCEPTED | status == POSMGR_ACCEPTED
TC-POSMGR-002 | SWE-REQ-012 | Busy if already processing                | isBusy=1 | pos=1 | POSMGR_BUSY | status==POSMGR_BUSY
TC-POSMGR-003 | SWE-REQ-013 | Range check: invalid position             | isBusy=0 | pos=8 | POSMGR_BUSY | status==POSMGR_BUSY
TC-POSMGR-004 | SWE-REQ-014 | Responsiveness: processes within <5ms     | isBusy=0, pos=5 | pos=5 | POSMGR_ACCEPTED | completes in <5ms

------------------------------------------------------------
UNIT: Flap Control Logic
------------------------------------------------------------
Responsibilities:
  - Process move requests, command Motor Driver, halt on target/error, track state.
  - Implements: SWE-REQ-005, SWE-REQ-006, SWE-REQ-007, SWE-REQ-008, SWE-REQ-025, SWE-REQ-031, SWE-REQ-043
APIs: FlapControl_request(uint8_t target), FlapControl_stop(void)

Test Cases:
TC-FLAP-001 | SWE-REQ-005 | Issues move on valid cmd        | IDLE state, new cmd | target=2 | MotorDriver_start called, state=MOVING | validated via mock
TC-FLAP-002 | SWE-REQ-007 | Stops motor at target           | MOVING, actual==target | target=3 | MotorDriver_stop called, state=TARGET_REACHED
TC-FLAP-003 | SWE-REQ-008 | Stops motor on error feedback   | MOVING, error | target=2 | MotorDriver_stop called, state=ERROR
TC-FLAP-004 | SWE-REQ-025 | Monitors until position/error   | During move | any | MotorDriver_stop after correct cycle

------------------------------------------------------------
UNIT: Motor Driver Abstraction
------------------------------------------------------------
Responsibilities:
  - Drive GPIO/PWM, force OFF on init/error/redundancy.
  - Implements: SWE-REQ-006, SWE-REQ-007, SWE-REQ-008, SWE-REQ-009, SWE-REQ-011, SWE-REQ-020
APIs: MotorDriver_start(int8_t direction), MotorDriver_stop(void)

Test Cases:
TC-MOTDRV-001 | SWE-REQ-006 | Set GPIO/PWM on start call       | OFF, call start(dir=1) | dir=1 | GPIO/PWM mock set, motorState=ON
TC-MOTDRV-002 | SWE-REQ-007 | PWM OFF on stop call             | ON, call stop() | - | PWM mock disabled, motorState=OFF
TC-MOTDRV-003 | SWE-REQ-008 | Force OFF on error               | ON, simulate error | - | PWM OFF, motorState=OFF
TC-MOTDRV-004 | SWE-REQ-009 | OFF at init                      | After init() | - | motorState=OFF

------------------------------------------------------------
UNIT: Position Feedback Acquisition
------------------------------------------------------------
Responsibilities:
  - Map ADC to position, check out-of-range, flag errors.
  - Implements: SWE-REQ-013, SWE-REQ-014, SWE-REQ-029
APIs: position_feedback_get(uint8_t *pos, Status_t *status)

Test Cases:
TC-PSFDBK-001 | SWE-REQ-013 | Map valid ADC to correct pos      | ADC=1000 (mock) | - | pos=2, status=OK
TC-PSFDBK-002 | SWE-REQ-029 | Out-of-range ADC signals error    | ADC=50 (mock) | - | status=ERROR
TC-PSFDBK-003 | SWE-REQ-013 | Valid mapping for all table vals  | For all CalibTable[i] | - | pos=i, status=OK

------------------------------------------------------------
UNIT: Status Indicator Controller
------------------------------------------------------------
Responsibilities:
  - Sets LED states, single green at a time, ON at power-on.
  - Implements: SWE-REQ-015, SWE-REQ-016
APIs: StatusLED_set(uint8_t pos), PowerLED_on(void)

Test Cases:
TC-STATLED-001 | SWE-REQ-015 | Power LED set on startup      | init() then PowerLED_on() |  - | Status LED (mock)=ON
TC-STATLED-002 | SWE-REQ-016 | Only correct green LED active | set(pos=3) | pos=3 | Only one output high, others low (mock check)

------------------------------------------------------------
Isolation/Mocking:
  - All tests mock ADC_read, UART_read_byte, MotorDriver_start/stop, StatusLED_set, PowerLED_on
  - No integration tests, no real hardware, all deterministic/repeatable.
  - Stub/mocks for UART, ADC, GPIO, PWM required.

------------------------------------------------------------
EXAMPLE TEST CASE CODE (snippet, using CMocka style):
#include "command_handler.h"
#include "mock_position_manager.h"
void test_validate_and_dispatch_valid(void) {
    mock_PositionManager_command_ExpectAndReturn(2, POSMGR_ACCEPTED);
    CmdStatus_t stat = validate_and_dispatch(2);
    assert_int_equal(stat, CMD_ACCEPTED);
}
