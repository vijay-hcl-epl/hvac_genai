## 4. Isolation Rules
- All hardware signals must be mocked (ADC, GPIO, PWM, UART)
- No real hardware access; all test benches are on host (SIL)
- No integration or system tests allowed in this plan
- All tests repeatable, deterministic

## 5. Example C Unit Test Stubs (Mocked)
```c
// Example for uart_handler
#include "unity.h"
#include "uart_handler.h"
void setUp(void) { uart_handler_init(); }
void tearDown(void) {}
void test_uart_parse_valid_0(void) {
    uart_rx_callback(0);
    uint8_t cmd;
    TEST_ASSERT_TRUE(uart_get_valid_command(&cmd));
    TEST_ASSERT_EQUAL_UINT8(0, cmd);
}
void test_uart_reject_out_of_range(void) {
    uart_rx_callback(0xFF);
    uint8_t cmd;
    TEST_ASSERT_FALSE(uart_get_valid_command(&cmd));
    TEST_ASSERT_TRUE(uart_has_error());
}
```
