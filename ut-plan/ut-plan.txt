-------------------------------------------------------------------------------------------
UNIT: Command Handler
Responsible for: Accept/validate/route user commands, error status, feedback
SW-REQs: SWE-REQ-001, SWE-REQ-002, SWE-REQ-003, SWE-REQ-015

Test Cases:
- TC-CH-01 | SWE-REQ-001 | Valid Command Acceptance
  PRE: System in Idle
  INPUT: UART RX, buf[0]=0x12, len=1
  EXPECT: valid_cmd_flag==1, last_cmd_status==0, status sent, Position Control invoked
- TC-CH-02 | SWE-REQ-002 | Malformed Command Handling
  PRE: Any
  INPUT: UART RX, len=0 or buf==NULL
  EXPECT: last_cmd_status==1, error status sent
- TC-CH-03 | SWE-REQ-002 | Out-of-Range Command Handling
  PRE: Any
  INPUT: buf[0]=0xFF (beyond limit)
  EXPECT: last_cmd_status==1, error status sent
- TC-CH-04 | SWE-REQ-003 | Status Response is Correct
  PRE: After valid
  INPUT: get_last_cmd_status()
  EXPECT: return==0 (OK)
- TC-CH-05 | SWE-REQ-015 | UART Interface Use (mocked)
  PRE: Any
  INPUT: Internal command
  EXPECT: hal_uart_write() called with expected status bytes

-------------------------------------------------------------------------------------------
UNIT: Position Control
Responsible for: Verify target, check bounds, update position, trigger motor
SW-REQs: SWE-REQ-004,SWE-REQ-005,SWE-REQ-006,SWE-REQ-007

Test Cases:
- TC-PC-01 | SWE-REQ-004 | Target Range Acceptance
  INPUT: set_target_position(45)
  EXPECT: Valid, triggers Motor Control
- TC-PC-02 | SWE-REQ-004 | Reject Out-Of-Range Target
  INPUT: set_target_position(-1 or 150)
  EXPECT: pos_verify_result==1
- TC-PC-03 | SWE-REQ-006 | Internal Position Tracking
  INPUT: update_on_feedback(45) after target=45
  EXPECT: current_position==target_position, stop_drive() called
- TC-PC-04 | SWE-REQ-007 | Accuracy Enforcement
  INPUT: update_on_feedback(45 or 44) target=45
  EXPECT: Accept if error <=2%

-------------------------------------------------------------------------------------------
UNIT: Motor Control
Responsible for: Issue motor start/stop, direction, fault detection
SW-REQs: SWE-REQ-008, SWE-REQ-009, SWE-REQ-010, SWE-REQ-011

Test Cases:
- TC-MC-01 | SWE-REQ-008 | Start in Correct Direction
  INPUT: start_drive(DIR_FORWARD)
  EXPECT: GPIO set correctly, motor_state==1
- TC-MC-02 | SWE-REQ-009 | Stop Command
  INPUT: stop_drive()
  EXPECT: GPIO(s) cleared, motor_state==0
- TC-MC-03 | SWE-REQ-010 | Simulated Overcurrent Fault
  INPUT: inject fault via HAL/mocks
  EXPECT: stop_drive(), error flagged

-------------------------------------------------------------------------------------------
UNIT: Feedback Acquisition
Responsible for: ADC read, filter, range check, sensor fault
SW-REQs: SWE-REQ-012, SWE-REQ-013, SWE-REQ-016

Test Cases:
- TC-FA-01 | SWE-REQ-012 | Valid ADC Result Handling

  EXPECT: filtered_position==50, status==OK
- TC-FA-02 | SWE-REQ-013 | Out-of-Range ADC
  INPUT: mock hal_adc_read returning -10
  EXPECT: sensor_status==1 (error flagged)

-------------------------
ISOLATION RULES
-------------------------
- All ADC/GPIO/PWM/UART accessed code must be executed with full hardware abstraction -- use mocks.
- All tests deterministic and repeatable.
- No tests on real hardware or involving integration.

    handle_uart_rx(buf, 1);

    assert(last_cmd_status==0);
    // assert mock set_target_position called
}
