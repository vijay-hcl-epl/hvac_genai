# SWE.4 Unit Test Plan – HVAC Flap Actuator

## Software Units Under Test
1. Command Handler Unit
2. Flap Control Unit
3. Motor Control Unit
4. Feedback Acquisition & Processing Unit
5. LED Indication Unit
6. Configuration & Calibration Unit

## Test Plan Principles
- All hardware dependencies (ADC, GPIO, PWM, UART) are to be mocked/stubbed.
- Test environment requires no real MCU or board hardware.
- Each unit is isolated; no integration or end-to-end behavior.
- All test cases are deterministic and repeatable.

---

## UNIT: Command Handler Unit
### Responsibilities
- Parse UART command [0–5], reject invalids, deliver valid to Flap Control, count parse failures
### Allocated SW-REQs: SWE-REQ-001, SWE-REQ-002, SWE-REQ-003, SWE-REQ-004, SWE-REQ-005, SWE-REQ-038

### Test Cases:
| Test Case ID | SW-REQ Ref | Test Objective | Preconditions | Input | Expected Result | Pass Criteria |
|--------------|--------------|----------------|---------------|--------|-----------------|--------------|
| CH-01 | SWE-REQ-001 | Parse valid UART cmd '2' | command_ready=false | '2' | get_next_command()=2 | Command delivered |
| CH-02 | SWE-REQ-002 | Reject invalid UART cmd 'x' | command_ready=false | 'x' | get_next_command()=INVALID | Parse fail count++ |
| CH-03 | SWE-REQ-002 | Ignore cmd out of range '8' | command_ready=false | '8' | get_next_command()=INVALID | Parse fail count++ |
| CH-04 | SWE-REQ-005 | Ignore multiple in-flight commands | command_ready=true | '3' | get_next_command() unchanged | No new command |
| CH-05 | SWE-REQ-003 | Do not acknowledge invalid cmd | command_ready=false | 'A' | No output | No ACK, silent fail |

|--------------|------------|---------------|---------------|--------|----------------|--------------|
| FC-01 | SWE-REQ-006 | Move to new position | FLAP_IDLE | cmd:target≠current | Motor start, move_pending=true | flap_state=FLAP_MOVING |
| FC-02 | SWE-REQ-007 | Stop at correct logical pos | FLAP_MOVING | feedback=target | stop_motor() | flap_state=FLAP_IDLE |

void test_CH_01_parse_valid_cmd(void) {
    uart_rx_handler('2');
    TEST_ASSERT_TRUE(is_command_ready());
    TEST_ASSERT_EQUAL(2, get_next_command());
}
