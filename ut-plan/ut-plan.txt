# SWE.4 Unit Test Plan – HVAC Flap Actuator

## 1. Introduction
This unit test plan covers all software units and public APIs of the HVAC Flap Actuator project as implemented in `code_bundle.txt`, and traces test cases back to low-level design and software requirements for ASPICE SWE.4.

## 2. List of Software Units
- Command Parser (`command_parser.h/.c`)
- Flap Control Logic (`flap_control.h/.c`)
- Motor Driver (`motor_driver.h/.c`)
- Feedback Processor (`feedback_processor.h/.c`)
- LED Status Handler (`led_status.h/.c`)
- System Startup/Initialization (`system_init.h/.c`)

## 5. Example C Unit Test Stubs (for Command Parser)
```c
#include "command_parser.h"
#include <assert.h>
#include <string.h>

void test_TC_CP_01() {
    command_parser_t inst;
    command_parser_init(&inst);
    command_parser_process_byte(&inst, 0x20);
    assert(inst.valid && inst.latest_command == 0x20);
}

void test_TC_CP_02() {
    command_parser_t inst;
    command_parser_init(&inst);
    command_parser_process_byte(&inst, 0x17);
    assert(!inst.valid && inst.state == CMD_STATE_INVALID);
}
```

## 6. Isolation Notes
- Mocks MUST be used for device inputs (ADC/UART/GPIO)
- Real hardware excluded
- Test environment: deterministic, repeatable
- No integration or OS-scheduling
