Unit: User Command IF
Responsibilities: Handles UART/LIN command receipt, protocol decode, invokes flap logic. Invalid/malformed command rejection and error notification.
Allocated SW-REQ IDs: SWE-REQ-001, SWE-REQ-002, SWE-REQ-003, SWE-REQ-018, SWE-REQ-019, SWE-REQ-020, SWE-REQ-022, SWE-REQ-032

Test Cases:
TC-UCIF-01 (SWE-REQ-001): Decode valid command [0-5].
  - Objective: Ensure received value in [0-5] is parsed and passed to FlapCtrl_MoveTo().
  - Precond: HW/driver RX buffer loaded with valid frame.
  - Input: UART frame [cmd=3].
  - Expected: Cmd_Received(3) calls FlapCtrl_MoveTo(3).
  - Result: PASS if correct function invoked.

TC-UCIF-02 (SWE-REQ-002): Reject malformed/invalid frame.
  - Objective: Do not trigger MCU error or undefined state for bad frame.
  - Precond: Malformed UART (bad checksum, length, or value).
  - Input: UART frame [bad checksum/too short].
  - Expected: Cmd_Error(error code) called, MCU continues.
  - Result: PASS if error signaled, no crash/reset.

TC-UCIF-03 (SWE-REQ-003): Response sent for valid/invalid command.
  - Objective: Generate ACK/NACK as protocol specifies.
  - Precond: Valid or invalid frame arrives.
  - Input: frame with cmd=5; frame with out-of-range cmd=7.
  - Expected: ACK for valid, NACK for invalid.
  - Result: PASS if UART responds correctly.
