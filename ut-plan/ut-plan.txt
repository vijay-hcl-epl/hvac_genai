====================================================
ASPICE SWE.4 UNIT TEST PLAN – HVAC FLAP ACTUATOR
====================================================

INPUTS:
- sw-reqs/sw-reqs.txt (SWE.1/SWE.4)
- sw-lld/sw-lld.txt (SWE.3)
- codegen/code_bundle.txt

Units derived from LLD/code:
  1. User Command Handler (UCH)
  2. Application Logic (APPL)
  3. Motor Controller (MC)
  4. Feedback Acquisition (FA)
  5. Status Indicator (SI)

====================================================
1. TEST PLAN STRUCTURE
====================================================
Each unit is tested in isolation. ADC, GPIO, PWM, UART, and hardware dependencies are mocked. No integration or real hardware tests. Every test is deterministic, repeatable, and covers all normal/abnormal scenarios.

Each test case includes:
- Test Case ID
- SW-REQ Reference(s)
- Test Objective
- Preconditions
- Test Input
- Expected Result
- Pass/Fail Criteria

------------------------------
Responsibility: Parse UART RX to integer command (0–5), reject invalid/out-of-range. Single command in process.
Allocated SW-REQs: SWE-REQ-001, SWE-REQ-002, SWE-REQ-003, SWE-REQ-025, SWE-REQ-018

| UCH-TC-02  | 001,002,025 | Reject out-of-range command '8'                                             | UART idle, buffer empty             | ASCII '8'    | parse_result=CMD_OUT_OF_RANGE, valid=false       | must not return command  |
