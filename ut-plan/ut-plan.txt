- Expected Result

== 3. DETAILED UNIT TEST CASES ==

------------------------------
1. Initialization/Startup Unit (init_startup)
Responsibilities: System/hardware startup, peripheral setup, reading initial flap position, setting Power ON LED
SW-REQs: SWE-REQ-024, SWE-REQ-025, SWE-REQ-011

Test Case: INIT_001
  SW-REQ: SWE-REQ-024
  Objective: Ensure startup initializes all peripherals and enters ready state.
  Preconditions: System powered up
  Input: None (startup event)
  Expected: Peripherals configured, ready state signaled
  Criteria: All API calls made, status is success

Test Case: INIT_002
  SW-REQ: SWE-REQ-025
  Objective: Read and store initial flap position on power-up.
  Preconditions: System just initialized
  Input: None
  Expected: Flap position value available after startup
  Criteria: get_flap_position() called once, returns valid (0..5) or invalid

Test Case: INIT_003
  SW-REQ: SWE-REQ-011
  Objective: Ensure motor is OFF at startup completion.
  Preconditions: System init complete
  Input: None
  Expected: motor_stop() called
  Criteria: Motor output signals inactive

------------------------------
2. Command Input Unit (cmd_input)
Responsibilities: UART command decode/validation/filtering
SW-REQs: SWE-REQ-001, SWE-REQ-002, SWE-REQ-003, SWE-REQ-004, SWE-REQ-019

Test Case: CMD_001
  SW-REQ: SWE-REQ-001, SWE-REQ-019
  Objective: Accept valid UART commands 0–5 as flap positions
  Preconditions: System initialized
  Input: UART RX byte = '0'..'5'
  Expected: get_decoded_command() returns 0..5
  Criteria: Output matches input, within range

Test Case: CMD_002
  SW-REQ: SWE-REQ-002
  Objective: Reject invalid/out-of-range commands
  Preconditions: System initialized
  Input: UART RX byte outside '0'..'5'
  Expected: get_decoded_command() returns CMD_INVALID
  Criteria: No output change, no side effect

------------------------------
3. Feedback Acquisition Unit (feedback_acq)
Responsibilities: ADC reading, mapping, validation
SW-REQs: SWE-REQ-012, SWE-REQ-013, SWE-REQ-014, SWE-REQ-015, SWE-REQ-020, SWE-REQ-030, SWE-REQ-033

Test Case: FBK_001
  SW-REQ: SWE-REQ-012, SWE-REQ-020
  Objective: Acquire analog flap position, use ADC input
  Preconditions: ADC returns midrange value
  Input: ADC returns value in defined range for position 2
  Expected: get_flap_position() returns 2
  Criteria: Correct mapping

Test Case: FBK_002
  SW-REQ: SWE-REQ-013, SWE-REQ-030
  Objective: Boundary check, returns correct position for threshold edges
  Preconditions: ADC at border values
  Input: ADC returns range min/max
  Expected: get_flap_position() returns corresponding index
  Criteria: Validity met at edges

Test Case: FBK_003
  SW-REQ: SWE-REQ-015, SWE-REQ-033
  Objective: Out-of-range ADC disables motor, system idle
  Preconditions: ADC returns value not in any valid range
  Input: ADC returns 65535
  Expected: get_flap_position() returns FLAP_POS_INVALID; motor should stop
  Criteria: Correct signal to controller

------------------------------
4. Flap Position Control Unit (flap_ctrl)
Responsibilities: Command/position/state, movement logic
SW-REQs: SWE-REQ-005, SWE-REQ-006, SWE-REQ-007, SWE-REQ-024, SWE-REQ-025, SWE-REQ-026, SWE-REQ-027, SWE-REQ-028, SWE-REQ-031

Test Case: CTRL_001
  SW-REQ: SWE-REQ-005, SWE-REQ-006
  Objective: Move one position per valid command
  Preconditions: Idle, valid command received
  Input: Command transition (2→3)
  Expected: Motor actuates; position updates once
  Criteria: No skipped/intermediate moves

Test Case: CTRL_002
  SW-REQ: SWE-REQ-027
  Objective: Transition to idle after move or on error
  Preconditions: Currently moving
  Input: Target position reached
  Expected: System enters idle, disables motor, LED updated
  Criteria: Only one move, correct final state

------------------------------
5. Motor Actuation Unit (motor_act)
Responsibilities: Motor drive/stop on control request
SW-REQs: SWE-REQ-008, SWE-REQ-009, SWE-REQ-010, SWE-REQ-011, SWE-REQ-021

Test Case: MOTOR_001
  SW-REQ: SWE-REQ-008, SWE-REQ-021
  Objective: Motor ignited correctly for move
  Preconditions: Controller requests move
  Input: motor_move(dir)
  Expected: Output pins/pwm set for indicated direction
  Criteria: Signals match direction

Test Case: MOTOR_002
  SW-REQ: SWE-REQ-009, SWE-REQ-011
  Objective: Motor stops when position reached, at startup/idle
  Preconditions: Controller requests stop
  Input: motor_stop()
  Expected: Output pins/pwm all off
  Criteria: Motor inactive

------------------------------
6. Status Indication Unit (status_ind)
Responsibilities: Drive power and position LED signals
SW-REQs: SWE-REQ-016, SWE-REQ-017, SWE-REQ-018, SWE-REQ-022

Test Case: STATUS_001
  SW-REQ: SWE-REQ-016
  Objective: Power LED ON after init
  Preconditions: System started
  Input: init_start() complete
  Expected: set_led_state(6) called
  Criteria: GPIO for power LED active

Test Case: STATUS_002
  SW-REQ: SWE-REQ-017, SWE-REQ-018
  Objective: Only position LED ON; all others OFF on change
  Preconditions: Flap position update
  Input: set_led_state(idx)
  Expected: idx LED ON, others OFF
  Criteria: Only one LED/gpio active

== 6. EXAMPLE UNIT TEST STUBS (C) ==

// Example: cmd_input unit: test decode/validation
#include "unity.h"
#include "cmd_input.h"
void test_valid_cmd_accepted(void) {
    cmd_input_on_uart_rx('3');
    TEST_ASSERT_EQUAL_UINT8(3, get_decoded_command());
}
void test_invalid_cmd_rejected(void) {
    cmd_input_on_uart_rx('a');
    TEST_ASSERT_EQUAL_UINT8(CMD_INVALID, get_decoded_command());
}
