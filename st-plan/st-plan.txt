=====================
System Qualification Test Specification (SYS.5)
Automotive HVAC Flap Actuator – MOTIX™ TLE9851QXW
=====================

Technical References Used:
- infineon-tle9851qxw-datasheet-en.pdf: §3 (Supply), §4 (Power modes), §17 (CCU6/PWM), §21 (ADC), §26-27 (Bridge driver), Pinout tables, §29.11 (HS switch)
- infineon-tle985xqx-usermanual-en.pdf: §4 (Modes), §18 (CCU6), §19 (UART/LIN), §27/29 (Bridge, App Example), Application Info

All test hardware features, interfaces and boundaries derived strictly from above.


1. Introduction / Scope
-----------------------
This System Qualification Test Specification (SYS.5) covers end-to-end requirements-based validation of the HVAC flap actuator system, implemented on Infineon TLE9851QXW. Tests address only system-level externally observable behavior. No unit or integration tests included.

2. Traceability & Coverage
--------------------------
Each test case is mapped directly to one or more System Requirement IDs (SYS-REQ-XXX). Test areas are:
 1) Power-Up & Initialization
 2) Valid Flap Position Commands
 3) Invalid & Boundary Conditions
 4) Position Feedback & Monitoring
 5) Motor Control
 6) LED Status Indication
 7) End-to-End User Command–to–Feedback

3. System Test Cases
-------------------

====================
1) Power-Up & Initialization
====================

Test Case ID: SYS-TC-001
Mapped System Requirement IDs: SYS-REQ-001, SYS-REQ-022, SYS-REQ-029
Test Objective: Verify hardware initialization, all peripherals (UART, ADC, Bridge) are configured, motor remains off, and initial flap position is detected and stored.
Preconditions: System powered off, flap in random position.
Test Inputs: Power-on (apply 12V, GND) to system.
Test Steps:
 1. Power up device.
 2. Observe startup sequence (LEDs, UART, or scope on motor pins).
 3. Monitor UART for initialization messages.
Expected Results:
 - Peripherals initialize per datasheet/requirements.
 - Motor does not move until position command received.
 - System stores detected initial flap position.
 - Status LED (if present) indicates readiness.
Pass/Fail: All results as above are observed, and no motor actuation/noise occurs during startup.

Test Case ID: SYS-TC-002
Mapped System Requirement IDs: SYS-REQ-002, SYS-REQ-022
Test Objective: Verify system ONLY operates within automotive supply range (5.5V–28V).
Preconditions: Device at room temp.
Test Inputs: Sweep power supply between 4V–30V.
Test Steps:
 1. Power system sequentially at 4V, 5.5V, 12V, 28V, 30V.
 2. At each step, observe system activity and feedback.
Expected Results:
 - No function below 5.5V or above 28V.
 - All features operate normally between 5.5V–28V.
Pass/Fail: Functions only within specified supply range; out-of-range voltages produce correct startup abort/fault (no reset/lock-up).

====================
2) Valid Flap Position Commands
====================

Test Case ID: SYS-TC-003
Mapped System Requirement IDs: SYS-REQ-003, SYS-REQ-004, SYS-REQ-005, SYS-REQ-011, SYS-REQ-013, SYS-REQ-018, SYS-REQ-033
Test Objective: Validate all 6 flap command positions (0–5) produce correct mechanical movement, ADC feedback, and timing.
Preconditions: System initialized, valid UART/LIN connection.
Test Inputs: UART (or LIN) position commands 0, 1, 2, 3, 4, 5.
Test Steps:
 For each position:
 1. Transmit command (e.g., UART: 'POS:0', then 'POS:1',...) with ≥3s dwell.
 2. Observe decay, direction and stop of motor.
 3. Record ADC feedback.
 4. Observe response timing.
Expected Results:
 - Motor moves in correct direction to new position with no overshoot.
 - Stops at ADC threshold for each target.
 - ‘Completed’ response sent within 100ms after position reached.
Pass/Fail: All target positions reachable, correct movement, feedback & no overshoot/timing failures.

====================
3) Invalid & Boundary Conditions
====================

Test Case ID: SYS-TC-004
Mapped System Requirement IDs: SYS-REQ-017, SYS-REQ-035
Test Objective: Out-of-range or malformed UART/LIN commands are ignored. Out-of-range ADC values cause safe motor stop.
Preconditions: System ready, UART/LIN active.
Test Inputs: UART: 'POS:-1', 'POS:6', 'INVALID', or bit-flip noise. ADC calibration: simulate <0 or >4095 input on analog in.
Test Steps:
 1. Transmit invalid commands.
 2. During normal move, inject ADC error (force pin to GND or Vdd using test hook).
Expected Results:
 - No reset or undefined state.
 - Invalid commands ignored, system remains operational.
 - For ADC out-of-range, motor stops but system is responsive to next valid command.
Pass/Fail: No reset, crash, or unnecessary motor activation during/after fault input.

Test Case ID: SYS-TC-005
Mapped System Requirement IDs: SYS-REQ-017, SYS-REQ-023, SYS-REQ-034
Test Objective: System stability during rapid and/or conflicting commands.
Preconditions: All initialized.
Test Inputs: Rapid sequence of position commands, noise or conflicting position input while moving.
Test Steps:
 1. Transmit two valid commands in <200ms gap (e.g., POS:1 → POS:4 quickly).
 2. Issue overlapping/contradictory command while movement.
Expected Results:
 - System does not lock up, misbehave, or move erratically.
 - Only latest command executed, no double-move or unexpected action.
Pass/Fail: One movement per valid command, no instability, system does not reset/lock.

====================
4) Position Feedback & Monitoring
====================

Test Case ID: SYS-TC-006
Mapped System Requirement IDs: SYS-REQ-006, SYS-REQ-013, SYS-REQ-014
Test Objective: Verify ADC-based position monitoring, continuous update, and proper out-of-range handling.
Preconditions: Flap position at mid-value.
Test Inputs: Physical movement of flap and/or potentiometer, simulated bridge/ADC error.
Test Steps:
 1. Move flap by hand during idle (simulate backlash, slip, or slow drift).
 2. Inject open/short at potentiometer to simulate sensor error.
Expected Results:
 - Flap position updates correctly as ADC moves within range.
 - Out-of-range disables bridge and stops motor/updates status.
Pass/Fail: System always tracks feedback. Any sensor error halts motor, no hazardous behavior seen.

====================
5) Motor Control Behavior
====================

Test Case ID: SYS-TC-007
Mapped System Requirement IDs: SYS-REQ-007, SYS-REQ-008, SYS-REQ-009, SYS-REQ-010, SYS-REQ-015, SYS-REQ-024
Test Objective: Verify correct bridge/FET drive, PWM output for motor, state transitions (hold/brake), and response to hardware faults (e.g., overcurrent, overtemp).
Preconditions: System ready, test points on bridge driver/HS pins.
Test Inputs: UART move commands, stimulate overcurrent/open-load (bridge) as per UM test mode, heat motor driver with hot air gun (>125°C), force high or low loads.
Test Steps:
 1. Command flap positions and observe bridge outputs & PWM.
 2. Simulate/force hardware fault (short, open, heat).
Expected Results:
 - Correct FETs enable, correct PWM observed.
 - Fault detection disables bridge/motor and sets fault.
 - System resumes after clear fault per requirements
Pass/Fail: All motor states, PWM, and protections exercised with design intent.

====================
6) LED Status Indication
====================

Test Case ID: SYS-TC-008
Mapped System Requirement IDs: SYS-REQ-019, SYS-REQ-020, SYS-REQ-029
Test Objective: Validate status LED (or HS driver output) for system power and flap position indication.
Preconditions: LEDs connected, observer ready.
Test Inputs: All valid and invalid position/user commands.
Test Steps:
 1. Observe LED(s) at power-up.
 2. Issue flap position commands, verify LEDs match (one on at a time, others off, per position).
 3. Issue invalid command, observe status/fault signal.
Expected Results:
 - Power LED toggles correctly at init and shutdown.
 - Only correct position LED (or status output) lights at one time; boundaries respected.
Pass/Fail: LED/state output behavior perfectly matches command and feedback.

====================
7) End-to-End Command–to–Feedback Behavior
====================

Test Case ID: SYS-TC-009
Mapped System Requirement IDs: SYS-REQ-003, SYS-REQ-004, SYS-REQ-005, SYS-REQ-018, SYS-REQ-033
Test Objective: Validate user command triggers correct flap movement, stops at correct position, ADC confirms result, status updated, all within max timing.
Preconditions: System all functional, logger on UART, flap in random position.
Test Inputs: UART/LIN command to new random position.
Test Steps:
 1. Issue position command.
 2. Observe system response (move, stop, feedback, status output, debug message).
 3. Repeat for each possible position and random start.
Expected Results:
 - Motor actuates, ADC confirms stop at correct position.
 - UART/LIN/LED feedback confirms within ≤100ms.
 - No incorrect or unintended action.
Pass/Fail: All normal and random scenarios performed correctly and timely per requirements.
