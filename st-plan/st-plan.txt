==============================
SYSTEM QUALIFICATION TEST SPECIFICATION (SYS.5)
==============================

Project: HVAC Flap Actuator System
Branch: marsecnd-13b

Scope: This document defines the system qualification (end-to-end) tests for the full integration of the HVAC flap actuator prototype on bench hardware. All test cases validate externally observable behavior per system requirements. All software internal tests, architecture or unit/integration tests are excluded by scope and process constraint.

SYSTEM REQUIREMENT IDS: See sys-reqs/sys-reqs.txt in branch marsecnd-13b (latest commit SHA documented in test plan header).

Test Environment: Target STM32F407G-DISC1 MCU, connected bench setup (motor, potentiometer, L298N driver, LEDs, UART PC connection), powered by stable 12V supply. Test supervisor via PC/UART, observation manual for LEDs and flap.

==================================================================
TEST CASES
==================================================================

TEST CASE ID: SYS-TC-001
Mapped System Req: SYS-REQ-025, SYS-REQ-026, SYS-REQ-013, SYS-REQ-022, SYS-REQ-023
Test Objective: Verify correct power-up, peripheral initialization, safe startup, power/LED indication
Preconditions: System fully powered OFF, hardware correct, UART connected
Test Inputs: Power ON event
Test Steps:
 1. Ensure system is powered off
 2. Power ON the system
 3. Observe LEDs and motor
Expected Results:
 - Power LED turns ON (SYS-REQ-022)
 - System initializes all peripherals (implied by LED flash/idle)
 - Motor remains OFF after startup (SYS-REQ-013)
 - Current flap position detected (observe position LEDs)
 - One position LED reflects initial position (SYS-REQ-026,023)
Pass/Fail: As Expected = PASS; Any other outcome = FAIL

TEST CASE ID: SYS-TC-002
Mapped System Req: SYS-REQ-006, SYS-REQ-007, SYS-REQ-008, SYS-REQ-019, SYS-REQ-016, SYS-REQ-009, SYS-REQ-015, SYS-REQ-011, SYS-REQ-012, SYS-REQ-028, SYS-REQ-041, SYS-REQ-049
Test Objective: Valid position commands move flap through all positions; correct motor and LED behavior
Preconditions: System powered ON, idle, UART ready, flap at any position
Test Inputs: UART commands: 0, 1, 2, 3, 4, 5 (send each, observe outcome)
Test Steps:
 For each target position:
 1. Send valid position number via UART
 2. Observe flap movement, then LED response
Expected Results:
 - Motor rotates only as needed to reach target (SYS-REQ-011)
 - Motor stops at precise target (SYS-REQ-012)
 - No overshoot or incorrect motion (SYS-REQ-008,012,028)
 - Correct position LED ON for new position, only one at a time (SYS-REQ-023)
 - Flap matches requested position per feedback
Pass/Fail: All requirements confirmed for ALL positions = PASS; any error in any case = FAIL

TEST CASE ID: SYS-TC-003
Mapped System Req: SYS-REQ-020, SYS-REQ-021, SYS-REQ-043, SYS-REQ-017, SYS-REQ-042, SYS-REQ-029
Test Objective: Check response to invalid/boundary UART commands and ADC out-of-range
Preconditions: System ON and idle, flap at valid position
Test Inputs:
 - UART: out-of-range values (e.g., 6, 255, -1, 'A')
 - Physical: artificially force potentiometer voltage beyond expected ADC range
Test Steps:
 a) For UART: Send each invalid input, observe
 b) For ADC: Simulate out-of-range ADC
Expected Results:
 - Invalid UART commands are ignored, no movement (SYS-REQ-020,021,043,029)
 - No position or operating state changes
 - Out-of-range ADC: motor stops, system stays safe (SYS-REQ-017,042)
 - System does NOT reset, crash, or lock-up
Pass/Fail: All system states robust/not perturbed = PASS; else = FAIL

TEST CASE ID: SYS-TC-004
Mapped System Req: SYS-REQ-014, SYS-REQ-015, SYS-REQ-016, SYS-REQ-009, SYS-REQ-026, SYS-REQ-049
Test Objective: Verify continuous, correct position feedback and monitoring
Preconditions: System ON, ready
Test Inputs: Manually move flap (if possible), or cycle through commands 0–5
Test Steps:
 1. Repeatedly command flap to new positions
 2. Observe if actual position (visually/LED) always matches commanded position
 3. Confirm response to manual re-position or induced error
Expected Results:
 - ADC acquisition maps to logical positions
 - Position LEDs indicate correctly (SYS-REQ-023,049)
Pass/Fail: All state transitions and indications correct = PASS

TEST CASE ID: SYS-TC-005
Mapped System Req: SYS-REQ-010, SYS-REQ-011, SYS-REQ-012, SYS-REQ-041, SYS-REQ-042
Test Objective: Motor control logic — correct start/stop, direction, no unintended motion
Preconditions: System ON/idle, flap at any position
Test Inputs: UART commands for upward/downward movement, manual move attempts
Test Steps:
 a) Send command that will require both motor directions
 b) Attempt to move during system idle — verify no unintended movement
Expected Results:
 - Motor starts/stops as required by command
 - Motor direction correct for position (observe/mechanical markers)
 - No unintended movements or motion when idle
Pass/Fail: All logic verified for all directions = PASS

TEST CASE ID: SYS-TC-006
Mapped System Req: SYS-REQ-022, SYS-REQ-023, SYS-REQ-024, SYS-REQ-026
Test Objective: LED status/position indication at all times
Preconditions: System powered ON, UART ready
Test Inputs: Power cycle, UART exploration of 0–5, manual error conditions
Test Steps:
 1. Power up, observe LEDs
 2. Send position commands 0–5, check LED behavior
 3. Induce/restore error, check LED indication
Expected Results:
 - Power LED always ON when powered
 - Only one position LED ON, matching flap
 - LEDs reflect errors or initial position
Pass/Fail: All LED requirements visibly met = PASS

TEST CASE ID: SYS-TC-007
Mapped System Req: SYS-REQ-048, SYS-REQ-049, SYS-REQ-007, SYS-REQ-023, SYS-REQ-012
Test Objective: System E2E: command → movement → feedback → indication
Preconditions: System powered ON, UART, visual access to flap/LEDs
Test Inputs: Valid and invalid UART commands, power cycle, manual challenges
Test Steps:
 1. Issue a sequence of mixed valid and invalid commands
 2. Observe end-to-end effect: movement, feedback, LEDs
 3. Cycle power and repeat
Expected Results:
 - For every valid input: command results in correct motion, stop, and LED update
 - For invalid: ignore, no error, state unchanged
Pass/Fail: All stages complete as specified = PASS
