# System Qualification Test Specification (SYS.5)
## HVAC Flap Actuator System

## 1. Overview
This document defines the System Qualification Test Specification for the HVAC Flap Actuator as per ASPICE SYS.5 process, validating the integrated system against all System Requirements. Each test is to be executed on real hardware (bench setup), directly mapping to observable system behavior.

---

## 2. Test Case Template
- **Test Case ID**
- **Mapped System Requirement ID(s)**
- **Test Objective**
- **Preconditions**
- **Test Inputs**
- **Test Steps**
- **Expected Results**
- **Pass/Fail Criteria**

---

## 3. Test Cases

### 3.1 Power-Up & Initialization

#### SYS-TC-001 Power-on Peripheral Initialization
- **Mapped System Requirement ID(s):** SYS-REQ-017, SYS-REQ-018, SYS-REQ-019
- **Test Objective:** Verify all peripherals initialize, motor is OFF, position is sampled at power-on.
- **Preconditions:** System fully powered down, flap in any position.
- **Test Inputs:** Power ON event.
- **Test Steps:**
  1. Ensure system is disconnected from power.
  2. Position the flap arbitrarily.
  3. Power ON the system.
- **Expected Results:**
  - Power LED turns ON.
  - No actuator motion occurs.
  - Flap position is sampled (POSITION LED indicates current position).
- **Pass/Fail Criteria:**
  - Power LED active, motor inactive, initial position is reported correctly on LED.

---
#### SYS-TC-002 Initial Flap Position Detection
- **Mapped System Requirement ID(s):** SYS-REQ-019, SYS-REQ-015
- **Test Objective:** Confirm flap position sampled and displayed upon power-up.
- **Preconditions:** System powered OFF, flap is at a known position.
- **Test Inputs:** Power ON.
- **Test Steps:**
  1. Move flap by hand to a mid position (e.g., position 2).
  2. Power ON system.
- **Expected Results:**
  - System samples and displays current position via LED.
- **Pass/Fail Criteria:**
  - LED corresponding to mid position turns ON, other position LEDs are OFF.

---

### 3.2 Valid Flap Position Commands

#### SYS-TC-003 Command All Valid Positions
- **Mapped System Requirement ID(s):** SYS-REQ-001, SYS-REQ-002, SYS-REQ-003, SYS-REQ-022
- **Test Objective:** Check system moves flap to each supported position (0–5) when commanded.
- **Preconditions:** System powered ON, idle state.
- **Test Inputs:** UART commands for positions 0, 1, 2, 3, 4, 5 (one at a time)
- **Test Steps:**
  1. For each supported position, send UART command to target that position.
  2. Observe motor and position LED.
- **Expected Results:**
  - Motor drives flap in correct direction, stops at target.
  - Correct position LED ON after movement.
- **Pass/Fail Criteria:**
  - For each command, target position LED ON, motor stops, no overshoot.

---

### 3.3 Invalid & Boundary Conditions

#### SYS-TC-004 Out-of-Range Command Ignored
- **Mapped System Requirement ID(s):** SYS-REQ-004, SYS-REQ-013, SYS-REQ-021
- **Test Objective:** Validate system ignores UART commands outside supported range.
- **Preconditions:** System powered ON, flap at any valid position.
- **Test Inputs:** UART commands: -1, 6, 99, "x", etc.
- **Test Steps:**
  1. Send each invalid UART command.
  2. Observe LEDs, actuator, and UART (if echo/ack).
- **Expected Results:**
  - No movement, no change in position LED, system state preserved.
- **Pass/Fail Criteria:**
  - System remains idle; flap and LEDs unchanged after each invalid input.

---
#### SYS-TC-005 ADC Out-of-Range Handling
- **Mapped System Requirement ID(s):** SYS-REQ-011, SYS-REQ-031
- **Test Objective:** Verify motor stops if ADC position is out of valid range.
- **Preconditions:** System ON, simulating ADC error (disconnect potentiometer or inject out-of-range signal).
- **Test Inputs:** Out-of-range ADC value.
- **Test Steps:**
  1. With system active, disrupt potentiometer wiring, or inject out-of-range voltage.
  2. Issue valid position command.
- **Expected Results:**
  - Motor stops or does not start.
  - Status indication as per design (e.g., error LED or default state).
- **Pass/Fail Criteria:**
  - Motor is never operating with invalid ADC input.

---
#### SYS-TC-006 Command During Flap Movement
- **Mapped System Requirement ID(s):** SYS-REQ-029
- **Test Objective:** Confirm system processes only one command at a time.
- **Preconditions:** System moving flap to target position.
- **Test Inputs:** Send a new UART command while previous movement is still active.
- **Test Steps:**
  1. Send position command A.
  2. Before reaching A, send command B.
- **Expected Results:**
  - Second command ignored or queued as per requirements; no erratic motion or lock-up.
- **Pass/Fail Criteria:**
  - Flap either completes original movement or safely stops, but never executes both simultaneously.

---
### 3.4 Position Feedback & Monitoring

#### SYS-TC-007 ADC Feedback Mapping
- **Mapped System Requirement ID(s):** SYS-REQ-008, SYS-REQ-009, SYS-REQ-010
- **Test Objective:** ADC range maps accurately to all logical positions; monitoring is continuous.
- **Preconditions:** System ON.
- **Test Inputs:** Physical manipulation of flap to each position, monitoring ADC feedback (if possible).
- **Test Steps:**
  1. Move flap to various positions, confirm ADC reads as expected.
  2. System continuously displays correct position LED.
- **Expected Results:**
  - Each physical position results in correct logical/LED status with no lag.
- **Pass/Fail Criteria:**
  - Real-time position correspondence between flap, ADC, and LEDs.

---
### 3.5 Motor Control Behavior

#### SYS-TC-008 Motor Start/Stop & Direction
- **Mapped System Requirement ID(s):** SYS-REQ-005, SYS-REQ-006, SYS-REQ-007
- **Test Objective:** Validate motor only runs when required, always stops at target; directions correct.
- **Preconditions:** System ON, flap not at target.
- **Test Inputs:** UART command(s) for position movement.
- **Test Steps:**
  1. Command flap to new position (higher/lower).
  2. Observe and record direction, actuation duration.
- **Expected Results:**
  - Motor moves only as long as needed. Runs in correct direction. Stops when position reached.
- **Pass/Fail Criteria:**
  - Motor never runs while idle. Direction matches input. Stops at right position.

---
### 3.6 LED Status Indication

#### SYS-TC-009 Power LED Function
- **Mapped System Requirement ID(s):** SYS-REQ-014
- **Test Objective:** LED indicates power state.
- **Preconditions:** System OFF.
- **Test Inputs:** Power ON/OFF.
- **Test Steps:**
  1. Power ON, observe LED.
  2. Power OFF, observe LED turns OFF.
- **Expected Results:**
  - Power LED ON when powered, OFF otherwise.
- **Pass/Fail Criteria:**
  - LED faithfully tracks system power state.

---
#### SYS-TC-010 Position LED Indication
- **Mapped System Requirement ID(s):** SYS-REQ-015, SYS-REQ-016
- **Test Objective:** Only correct position LED illuminates after movement or after power-up.
- **Preconditions:** System in any valid state.
- **Test Inputs:** UART command or power cycle.
- **Test Steps:**
  1. Command a new position, or power cycle and observe.
- **Expected Results:**
  - Only target position LED ON. Updates correctly after change.
- **Pass/Fail Criteria:**
  - Only correct LED ON, all others OFF after event.

---
### 3.7 End-to-End Behavior

#### SYS-TC-011 Complete Command Flow
- **Mapped System Requirement ID(s):** SYS-REQ-001, SYS-REQ-002, SYS-REQ-003, SYS-REQ-009, SYS-REQ-010, SYS-REQ-015, SYS-REQ-016, SYS-REQ-020, SYS-REQ-035
- **Test Objective:** Validate integrated chain: user command → motor moves → feedback processed → LED updates.
- **Preconditions:** System idle, powered ON.
- **Test Inputs:** UART command for valid position.
- **Test Steps:**
  1. Send command for position 4 (if not already there).
  2. Observe sequence of events: motor, LED update, system idle when done.
- **Expected Results:**
  - Motor runs, stops at correct position. LED updates accurately. No error or spurious action.
- **Pass/Fail Criteria:**
  - All sub-functions (input, actuation, feedback, indication) operate in correct sequence, system returns to idle upon completion.
