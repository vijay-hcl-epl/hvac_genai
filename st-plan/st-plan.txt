HVAC FLAP ACTUATOR SYSTEM
Branch: mar-13a

1. INTRODUCTION
----------------
This document defines the System Qualification Test Specification (SYS.5) for the HVAC Flap Actuator System. The objective is to verify the complete integrated system functionality against all system-level requirements by executing tests on real hardware.

2. REFERENCES
--------------
- System Requirements: sys-reqs/sys-reqs.txt (SHA: cb95a61d3a784e30c3dca5b7ca08692f42166dfa)
- Software Architecture: sw-arch/sw-arch.txt (SHA: 524330d6122e718940ac3367c170254a354447a9)

3. TEST PLAN OVERVIEW
----------------------
- Tests are conducted on a lab-bench using the real embedded hardware as per the system requirements.
- Normal operation, boundary, and error cases are covered.
- Each test case is explicitly linked to System Requirement ID(s).
- Only observable system behaviors are tested (NOT internal logic).

4. TEST CASES
--------------

=====================================================================
1) POWER-UP & INITIALIZATION
=====================================================================

Test Case ID: SYS-TC-001
Mapped SysReqs: SYS-REQ-021, SYS-REQ-022, SYS-REQ-017
Test Objective: Verify system initializes peripherals, powers up LEDs correctly, and leaves motor OFF until a command is received.
Preconditions: Board is powered OFF.
Test Inputs: Power ON the system; no UART input.
Test Steps:
  1. Power ON the system.
  2. Observe all LEDs and motor state.
Expected Results:
  - Power LED is ON.
  - Only the correct position LED (per ADC reading) is ON.
  - Motor remains OFF.
Pass/Fail Criteria: As expected above; any deviation is Fail.

Test Case ID: SYS-TC-002
Mapped SysReqs: SYS-REQ-009, SYS-REQ-010, SYS-REQ-021
Test Objective: Verify flap position detection from ADC input at startup.
Preconditions: Flap and potentiometer at a valid logical position.
Test Inputs: Power ON.
Test Steps:
  1. Set flap to known position.
  2. Power ON system.
  3. Observe position LED.
Expected Results:
  - Corresponding position LED matches initial flap position.
Pass/Fail Criteria: As expected above; any deviation is Fail.

=====================================================================
2) VALID FLAP POSITION COMMANDS
=====================================================================

Test Case ID: SYS-TC-003
Mapped SysReqs: SYS-REQ-001, SYS-REQ-002, SYS-REQ-005, SYS-REQ-018
Test Objective: Verify system moves flap to each supported position (0-5) on command.
Preconditions: System in idle, power ON.
Test Inputs: UART command for each position (0 to 5).
Test Steps:
  For each value N in [0,1,2,3,4,5]:
    1. Send UART command for N.
    2. Observe motor and LEDs.
Expected Results:
  - Motor drives to new position.
  - Correct position LED lights after stop.
  - No further motor motion when position reached.
Pass/Fail Criteria: All above sub-tests succeed.

Test Case ID: SYS-TC-004
Mapped SysReqs: SYS-REQ-005, SYS-REQ-006, SYS-REQ-010
Test Objective: Verify correct motor direction, stop at target, and no overshoot.
Preconditions: Flap not at commanded position.
Test Inputs: UART position command.
Test Steps:
  1. Record current position.
  2. Issue command for different position.
  3. Monitor motor direction.
  4. Observe stop at target.
Expected Results:
  - Motor rotates in correct direction.
  - Stops cleanly at target; no overshoot/oscillation.
Pass/Fail Criteria: As above.

=====================================================================
3) INVALID & BOUNDARY CONDITIONS
=====================================================================

Test Case ID: SYS-TC-005
Mapped SysReqs: SYS-REQ-003, SYS-REQ-014, SYS-REQ-015
Test Objective: Validate handling of unsupported (out-of-range) commands (e.g. 6, 255, or malformed UART data).
Preconditions: System idle.
Test Inputs: UART send value 6; then 255; then invalid sequence (non-number).
Test Steps:
  1. Issue each invalid command.
  2. Observe system behavior.
Expected Results:
  - Command ignored.
  - No motor movement or LED change.
  - No error message or reset.
Pass/Fail Criteria: All above.

Test Case ID: SYS-TC-006
Mapped SysReqs: SYS-REQ-011, SYS-REQ-024, SYS-REQ-036
Test Objective: Validate behavior if ADC gives an out-of-range (invalid) value.
Preconditions: Potentiometer intentionally misadjusted/off-range.
Test Inputs: Power ON or trigger move.
Test Steps:
  1. Set ADC voltage out of calibration range.
  2. Observe motor and system LED states.
Expected Results:
  - Motor is stopped/safe.
  - No position LED indicates error.
  - System does not lock-up/reset.
Pass/Fail Criteria: As above.

Test Case ID: SYS-TC-007
Mapped SysReqs: SYS-REQ-004, SYS-REQ-016
Test Objective: Verify command during flap movement is ignored.
Preconditions: Flap moving (following command).
Test Inputs: Send a new UART command while actuator is in motion.
Test Steps:
  1. Initiate movement.
  2. Send new command.
Expected Results:
  - New command ignored until motion complete.
  - No system instability.
Pass/Fail Criteria: As above.

Test Case ID: SYS-TC-008
Mapped SysReqs: SYS-REQ-023, SYS-REQ-037
Test Objective: Verify stability—invalid UART does not reset/lock up the system.
Preconditions: System idle, UART active.
Test Inputs: Rapid/frequent invalid UART data.
Test Steps:
  1. Continuously send random/invalid data.
  2. Observe system.
Expected Results:
  - System ignores invalid input.
  - Operation continues for valid commands.
Pass/Fail Criteria: As above.

=====================================================================
4) POSITION FEEDBACK & MONITORING
=====================================================================

Test Case ID: SYS-TC-009
Mapped SysReqs: SYS-REQ-009, SYS-REQ-010, SYS-REQ-018
Test Objective: Verify ADC readings are mapped to all discrete positions and reported via LEDs.
Preconditions: Flap positions can be physically selected.
Test Inputs: Mechanically set potentiometer to each calibration step.
Test Steps:
  For each valid position:
    1. Move flap.
    2. Observe corresponding LED.
Expected Results:
  - LED matches physical position.
Pass/Fail Criteria: Full coverage and correct mapping.

Test Case ID: SYS-TC-010
Mapped SysReqs: SYS-REQ-012, SYS-REQ-040
Test Objective: Verify position monitoring is continuous/responsive (as observable at system level).
Preconditions: System idle.
Test Inputs: Manually alter flap position.
Test Steps:
  1. Move flap between positions without command.
  2. Observe system response (if any).
Expected Results:
  - No unintended reaction unless commanded via UART.
Pass/Fail Criteria: As above.

=====================================================================
5) MOTOR CONTROL BEHAVIOR
=====================================================================

Test Case ID: SYS-TC-011
Mapped SysReqs: SYS-REQ-005, SYS-REQ-007
Test Objective: Motor only runs on valid command; stops correctly after move.
Preconditions: System idle.
Test Inputs: UART command for flap movement.
Test Steps:
  1. Issue valid move.
  2. Observe start/stop.
Expected Results:
  - Motor activates only as required.
  - Stops at correct point.
Pass/Fail Criteria: Both observed.

Test Case ID: SYS-TC-012
Mapped SysReqs: SYS-REQ-005, SYS-REQ-019
Test Objective: No unintended movement without command or input change.
Preconditions: System idle after move.
Test Inputs: No new commands; no system reset.
Test Steps:
  1. Wait for period after idle.
Expected Results:
  - Motor remains OFF.
Pass/Fail Criteria: As above.

=====================================================================
6) LED STATUS INDICATION
=====================================================================

Test Case ID: SYS-TC-013
Mapped SysReqs: SYS-REQ-017, SYS-REQ-018
Test Objective: Verify power LED ON at all power states and only one position LED ON at a time.
Preconditions: System powered.
Test Inputs: Power ON and step through all positions.
Test Steps:
  1. Power ON, cycle positions.
  2. Observe LEDs.
Expected Results:
  - Power LED always ON.
  - Only target position LED illuminated at any time.
Pass/Fail Criteria: Powers/position LED logic as described.

Test Case ID: SYS-TC-014
Mapped SysReqs: SYS-REQ-019
Test Objective: Position and power LEDs update promptly after any commanded change.
Preconditions: System accepts command.
Test Inputs: UART position command.
Test Steps:
  1. Issue position command.
  2. Observe time taken for LED change.
Expected Results:
  - LED update is nearly immediate after movement complete.
Pass/Fail Criteria: As described.

=====================================================================
7) END-TO-END BEHAVIOR
=====================================================================

Test Case ID: SYS-TC-015
Mapped SysReqs: SYS-REQ-001, SYS-REQ-002, SYS-REQ-005, SYS-REQ-009, SYS-REQ-018, SYS-REQ-019, SYS-REQ-040
Test Objective: Verify full system chain: user command → motor action → position LED feedback.
Preconditions: System is on, idle.
Test Inputs: UART valid command, observe position change.
Test Steps:
  1. Issue supported command and directly observe all outputs (motor action, position LED update).
Expected Results:
  - Flap moves, stops, and correct position LED is shown.
Pass/Fail Criteria: All observable behaviors correct.
