TEST CASES
==========

SYS-TC-001: Power-Up Initialization
-----------------------------------
Mapped Sys. Req(s): SYS-REQ-013, SYS-REQ-015, SYS-REQ-014
Test Objective: Verify correct initialization (all peripherals) and status indication on power-up.
Preconditions: System powered OFF.
Test Inputs: Apply 12V (automotive supply) to power input.
Test Steps:
1. Connect system to bench supply, all peripherals attached.
2. Switch ON the system power.
3. Observe LEDs, UART messages.
Expected Results: All subsystems initialize; status LED and/or UART shows power-up or ready; no error/invalid state indicated.
Pass/Fail Criteria: Peripherals are active; power LED correct; no spurious actions; status per requirement.

SYS-TC-002: Flap Motor OFF after Power-Up
----------------------------------------
Mapped Sys. Req(s): SYS-REQ-015, SYS-REQ-019
Test Objective: Ensure flap motor is not energized after power-up before a valid command.
Preconditions: System just initialized (from SYS-TC-001).
Test Inputs: None (idle state).
Test Steps:
1. Observe actuator behavior for 10 seconds or as per system idle period.
Expected Results: Flap does not move; motor is not actuated; system is idle.
Pass/Fail Criteria: Zero motor activity; status output shows idle/ready.

SYS-TC-003: Initial Flap Position Detection
------------------------------------------
Mapped Sys. Req(s): SYS-REQ-008, SYS-REQ-015
Test Objective: Verify flap position sensor is read and position correctly acquired at power-up.
Preconditions: Flap at a random safe position; system powered ON.
Test Inputs: None.
Test Steps:
1. Power up system.
2. Probe UART output or use debug tool to observe detected position.
Expected Results: Initial position (within allowed range) reported via UART/status.
Pass/Fail Criteria: System detects valid position; Status LED (if equipped) correct.

SYS-TC-004: Valid Flap Position Command — Position 0
----------------------------------------------------
Mapped Sys. Req(s): SYS-REQ-001, SYS-REQ-011, SYS-REQ-013, SYS-REQ-017
Test Objective: Issue command for position 0 and verify accurate flap movement and reporting.
Preconditions: System initialized and in idle.
Test Inputs: UART: CMD:POS:0
Test Steps:
1. Send UART command for position 0.
2. Monitor actuator and feedback response.
3. Observe status LED/UART.
Expected Results: Flap moves to position 0, stops precisely, status indicates target reached, no overshoot.
Pass/Fail Criteria: Flap at position 0, indication correct, no unintended effects.

SYS-TC-005: Valid Flap Position Command — Position 5
----------------------------------------------------
Mapped Sys. Req(s): SYS-REQ-001, SYS-REQ-011, SYS-REQ-013, SYS-REQ-017
Test Objective: Issue command for position 5 and verify flap movement/indication as above.
Preconditions: Flap not at position 5, system in idle.
Test Inputs: UART: CMD:POS:5
Test Steps: As in SYS-TC-004 but command for position 5.
Expected Results: Flap moves to position 5, stops, correct status indication, no overshoot.
Pass/Fail Criteria: As above.

SYS-TC-006: Flap Moves in Correct Direction
-------------------------------------------
Mapped Sys. Req(s): SYS-REQ-004, SYS-REQ-005, SYS-REQ-021
Test Objective: Validate motor output/hardware logic — direction matches command.
Preconditions: Any valid state, known position.
Test Inputs: UART: CMD:POS:N (N=0,1...5)
Test Steps:
1. Send command for flap movement (increase/decrease).
2. Observe physical movement or motor terminal signals.
Expected Results: Motor direction matches intended (open/close or up/down as specified), no reversal.
Pass/Fail Criteria: Scope/capture matches command, correct movement direction.

SYS-TC-007: Motor Stops at Target Position
-----------------------------------------
Mapped Sys. Req(s): SYS-REQ-005, SYS-REQ-017
Test Objective: Ensure motor deactivates when correct position reached.
Preconditions: Mid-movement after valid position command.
Test Inputs: None (system auto behavior).
Test Steps:
1. Induce movement (command issued).
2. Observe system as feedback approaches setpoint.
Expected Results: Motor stops at correct position; indicator shows target reached.
Pass/Fail Criteria: No over-travel; feedback stable.

SYS-TC-008: No Overshoot on Flap
-------------------------------
Mapped Sys. Req(s): SYS-REQ-002, SYS-REQ-005
Test Objective: Motor/flap stops at limit; safe range enforced.
Preconditions: Near boundary; valid position command.
Test Inputs: UART: CMD:POS:0 or CMD:POS:5
Test Steps:
1. Send command to move flap near/mechanical min or max.
2. Monitor flap and position feedback.
Expected Results: Flap does not exceed mechanical limits.
