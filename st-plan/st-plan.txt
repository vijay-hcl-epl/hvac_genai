===================================================================
SYSTEM QUALIFICATION TEST SPECIFICATION (SYS.5)
HVAC FLAP ACTUATOR
===================================================================

Scope: This document specifies the complete set of system qualification tests (SYS.5) for the HVAC flap actuator prototype. All test cases validate observable system behavior on real hardware. Internal implementation, software integration, or unit/module interfaces are OUT OF SCOPE per constraints.

-------------------------------------------------------------------
TEST CASE TEMPLATE
-------------------------------------------------------------------
[Each test case uses the following format:]
- Test Case ID:
- Mapped System Requirement IDs:
- Test Objective:
- Preconditions:
- Test Inputs:
- Test Steps:
- Expected Results:
- Pass/Fail Criteria:

-------------------------------------------------------------------
1. POWER-UP & INITIALIZATION TEST CASES
-------------------------------------------------------------------

Test Case ID: SYS-TC-001
Mapped System Requirement IDs: SYS-REQ-008, SYS-REQ-019, SYS-REQ-020, SYS-REQ-017
Test Objective: Confirm that after power-up, all peripherals initialize, the power LED is ON, and the motor remains OFF until position is assessed.
Preconditions: System is powered OFF. Bench setup ready.
Test Inputs: Power ON event.
Test Steps:
  1. Power ON the system.
  2. Observe all status LEDs and motor state.
Expected Results:
  - Status (power) LED turns ON.
  - No movement from the flap/motor at startup.
  - System does not react to any input before turning ON/boot.
Pass/Fail Criteria: All expected visual and behavioral results are observed as described.

Test Case ID: SYS-TC-002
Mapped System Requirement IDs: SYS-REQ-019, SYS-REQ-025, SYS-REQ-008
Test Objective: Verify all peripherals (ADC, UART, GPIO, PWM) initialize properly before normal operation.
Preconditions: System is powered OFF.
Test Inputs: Power ON event.
Test Steps:
  1. Power ON the system.
  2. Verify by observation and UART input that system responds as ready after a short initialization interval.
Expected Results:
  - Flap does not move until initialized.
  - Status LED ON during and after init.
  - Valid UART commands ignored until init completes.
Pass/Fail Criteria: Peripherals ready, no unsolicited flap movement, correct LED indication.

-------------------------------------------------------------------
2. VALID FLAP POSITION COMMAND TESTS
-------------------------------------------------------------------

Test Case ID: SYS-TC-003
Mapped System Requirement IDs: SYS-REQ-001, SYS-REQ-002, SYS-REQ-006, SYS-REQ-010
Test Objective: Verify system accepts valid commands (0–5) and moves flap to each position, with correct motor action and stopping.
Preconditions: System initialized and idle.
Test Inputs: UART position command (0, 1, 2, 3, 4, 5 sent individually).
Test Steps (repeat for each position):
  1. Send UART command for a specific position value (0–5).
  2. Observe motor movement and final flap position.
  3. Observe corresponding position LED.
Expected Results:
  - Flap moves to and stops at target position.
  - Corresponding LED indicates selected position only.
  - No overshoot or motor oscillation after stopping.
Pass/Fail Criteria: All movement and LEDs as per requirements for each position.

Test Case ID: SYS-TC-004
Mapped System Requirement IDs: SYS-REQ-003, SYS-REQ-023
Test Objective: Confirm motor stops at the precise target position and the system retains position indication.
Preconditions: Flap not at commanded position.
Test Inputs: Valid UART command.
Test Steps:
  1. Command movement.
  2. Observe that motor stops exactly at target.
Expected Results:
  - No continued or unintended movement after position reached.
  - Correct position LED remains ON.
Pass/Fail Criteria: Motor ceases as soon as feedback matches the target; LED stays on.

-------------------------------------------------------------------
3. INVALID & BOUNDARY CONDITION TESTS
-------------------------------------------------------------------

Test Case ID: SYS-TC-005
Mapped System Requirement IDs: SYS-REQ-004, SYS-REQ-016, SYS-REQ-022, SYS-REQ-032, SYS-REQ-033
Test Objective: Validate system ignores and safely handles out-of-range or malformed UART/ADC values; no reset/lock-up occurs.
Preconditions: System initialized and waiting for valid input.
Test Inputs: UART command <0 or >5, random invalid bytes; force ADC to return out-of-range value via simulated sensor fault.
Test Steps:
  1. Inject invalid position command via UART.
  2. Inject random noise/illegal bytes.
  3. Force ADC (potentiometer) test condition for out-of-range.
Expected Results:
  - System rejects/ignores input; no movement, no crash.
  - Flap remains stable, system does not reset.
Pass/Fail Criteria: System behavior matches all expected results in each condition.

Test Case ID: SYS-TC-006
Mapped System Requirement IDs: SYS-REQ-005, SYS-REQ-028
Test Objective: Ensure only one command is in process; multiple simultaneous/overlapping commands are ignored while busy.
Preconditions: Flap is moving due to active command.
Test Inputs: Inject second command during ongoing flap movement.
Test Steps:
  1. Command valid movement.
  2. While movement in progress, send another command.
Expected Results:
  - Second command is ignored until first is complete.
  - No undefined/interleaved movement
Pass/Fail Criteria: Only the first movement is executed per cycle.

Test Case ID: SYS-TC-007
Mapped System Requirement IDs: SYS-REQ-033
Test Objective: Confirm system does not reset or lock up on any undefined input or hardware anomaly.
Preconditions: System running, inject error (as above) or disturb power.
Test Inputs: Quick cycling power or UART bursts.
Test Steps:
  1. Cycle power, send combined valid and invalid UART.
Expected Results:
  - System resumes correctly with no reset/lock-up
Pass/Fail Criteria: System is always recoverable and functional.

-------------------------------------------------------------------
4. POSITION FEEDBACK & MONITORING TESTS
-------------------------------------------------------------------

Test Case ID: SYS-TC-008
Mapped System Requirement IDs: SYS-REQ-010, SYS-REQ-011, SYS-REQ-013
Test Objective: Verify correct ADC acquisition and translation to logical positions; continuous monitoring.
Preconditions: System running, flap in various positions.
Test Inputs: Move flap physically; change potentiometer, send UART command.
Test Steps:
  1. Move flap with motor or (if possible) manually.
  2. Observe ADC readings, mapped position, and position LED.
Expected Results:
  - ADC is acquired and correctly mapped to logical value; corresponding LED indicates.
  - Continuous, real-time update (sub-second perceived delay)
Pass/Fail Criteria: Always accurate ADC-to-logical mapping, correct status indication, human-observable responsiveness.

Test Case ID: SYS-TC-009
Mapped System Requirement IDs: SYS-REQ-012, SYS-REQ-035, SYS-REQ-036
Test Objective: Validate ability to recalibrate ADC-to-position mapping and observe its effects.
Preconditions: System running, test calibration procedure/support.
Test Inputs: Use UART or available calibration function to change calibration data.
Test Steps:
  1. Change calibration.
  2. Send known UART command, observe mapping and indication
Expected Results:
  - Only updated mappings take effect; old mappings no longer used.
Pass/Fail Criteria: Calibration changes reflected visually and in behavior after modification.

-------------------------------------------------------------------
5. MOTOR CONTROL BEHAVIOR TESTS
-------------------------------------------------------------------

Test Case ID: SYS-TC-010
Mapped System Requirement IDs: SYS-REQ-007, SYS-REQ-008
Test Objective: Ensure motor functions (ON/OFF, direction, PWM/enable) are correct and no unintended motion occurs.
Preconditions: System in idle.
Test Inputs: Valid move command, forced direction reversal, power cycle.
Test Steps:
  1. Issue movement, observe flap direction
  2. Stop/interrupt, see if stops correctly.
Expected Results:
  - Motor only moves when and as commanded, stops precisely when required.
Pass/Fail Criteria: No erratic or uncommanded movement is ever seen.

-------------------------------------------------------------------
6. LED STATUS INDICATION TESTS
-------------------------------------------------------------------

Test Case ID: SYS-TC-011
Mapped System Requirement IDs: SYS-REQ-017, SYS-REQ-018
Test Objective: Validate correct operation of status and position LEDs.
Preconditions: System idle, powered.
Test Inputs: Power cycle, valid/invalid position commands.
Test Steps:
  1. Power ON/OFF system, observe status LED.
  2. Send position command, observe corresponding green LED only (one at a time).
Expected Results:
  - Power LED ON whenever system powered, OFF otherwise.
  - Only ONE position LED illuminates for actual flap position.
Pass/Fail Criteria: LEDs behave as requirements specify.

-------------------------------------------------------------------
7. END-TO-END SYSTEM BEHAVIOR TESTS
-------------------------------------------------------------------

Test Case ID: SYS-TC-012
Mapped System Requirement IDs: SYS-REQ-001, SYS-REQ-002, SYS-REQ-010, SYS-REQ-018
Test Objective: Full chain: command reception, movement, feedback, and correct LED output.
Preconditions: System idle, known flap start position.
Test Inputs: UART command for different valid positions.
Test Steps:
  1. Send valid command.
  2. Observe physical movement to new position.
  3. Confirm position LED indication.
Expected Results:
  - Command results in correct physical movement and position indication; chain is complete.
Pass/Fail Criteria: All steps operate smoothly from user input to observable system reaction.
