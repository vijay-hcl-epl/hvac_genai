SYSTEM QUALIFICATION TEST SPECIFICATION (SYS.5)
Automotive HVAC Flap Actuator — System Qualification Test Plan
Target Platform: MOTIX™ TLE9851QXW
Branch: hvdemo-143b

---

1.0 INTRODUCTION
This document defines the complete system-level (SYS.5) test specification for the HVAC flap actuator system, covering normal, boundary, and fault conditions as required for ASPICE Level 3. All tests validate the integrated system on real hardware and map explicitly to system requirement IDs.

2.0 TEST CASE STRUCTURE
Each test follows the template:
- Test Case ID
- Mapped System Requirement(s)
- Test Objective
- Preconditions
- Test Inputs
- Test Steps
- Expected Results
- Pass/Fail Criteria

3.0 TEST CASES

---

3.1 POWER-UP & INITIALIZATION

SYS-TC-001
- SYS-REQ: 060, 002, 014
- Objective: Verify all required peripherals initialize, system enters idle, flap/motor are off.
- Preconditions: System powered OFF
- Inputs: Supply voltage applied (nominal, 12V)
- Steps:
  1. Apply power to VS pin (12V)
  2. Observe initialization sequence (LEDs, UART/LIN, etc.)
- Expected: Motor is OFF. Status LED (if specified) indicates idle. UART/LIN ready.
- Criteria: System remains stable, idle, motor does not move until valid input.

SYS-TC-002
- SYS-REQ: 014, 060, 030
- Objective: Verify initial flap position detection/feedback mapping at startup.
- Preconditions: System powered OFF; Flap located at random position
- Inputs: Apply power
- Steps:
  1. Power ON
  2. Observe UART/LIN/LED status message for initial position
- Expected: System reports correct flap position (0–5). No motion is triggered.
- Criteria: Displayed position matches physical position per sensor.

---

3.2 VALID FLAP POSITION COMMANDS

SYS-TC-010
- SYS-REQ: 010, 011, 041, 062
- Objective: Command all valid positions, verify accurate execution
- Preconditions: System in idle; Flap at known position (0–5)
- Inputs: UART (or LIN) command [0] (repeat 1–5 in subcases)
- Steps:
  1. Send command for flap position N (N=0..5)
  2. Observe motor action; wait for stop
  3. Query status
- Expected: Flap moves to target, stops at correct position (no overshoot)
- Criteria: Final position == commanded; No further movement; Status indicates completion

SYS-TC-011
- SYS-REQ: 012, 021, 022, 066
- Objective: Correct motor direction and stop at target
- Preconditions: Idle; Flap at non-commanded position
- Inputs: UART/LIN command for new position
- Steps:
  1. Send command (e.g., from 2→4)
  2. Observe direction; wait for arrival
- Expected: Motor drives correct direction; stops precisely at threshold
- Criteria: No oscillations/overshoot, minimal delay per SYS-REQ-100

---

3.3 INVALID & BOUNDARY CONDITIONS

SYS-TC-020
- SYS-REQ: 013, 043, 064
- Objective: System ignores out-of-range/invalid inputs
- Preconditions: Flap initialized, idle
- Inputs: UART/LIN with command 6, 255, 'X', invalid bytes
- Steps:
  1. Issue invalid command(s)
  2. Observe state/status/LEDs
- Expected: No movement; Error indication (if specified)
- Criteria: System safe, state unchanged; Fault flagged if required

SYS-TC-021
- SYS-REQ: 033, 034, 111
- Objective: ADC out-of-range, sensor faults generate safe shutoff
- Preconditions: System idle; Flap position sensor disconnected or simulated out-of-range
- Inputs: Disconnect potentiometer; or simulate ADC value >1023 / <0
- Steps:
  1. Cause sensor fault
  2. Observe motor reaction
- Expected: Motor stops; Fault indicator/LED set; Event flagged on UART/LIN
- Criteria: No unsafe behavior; Fault remains until cleared.

SYS-TC-022
- SYS-REQ: 041, 064
- Objective: Ignore command during flap movement
- Preconditions: Flap in transition
- Inputs: Command during execution
- Steps:
  1. Command movement (e.g., 0→5)
  2. Before arrival, command another move
- Expected: First movement completes, second is queued or ignored (per SW design, but must not disrupt state)
- Criteria: System is stable, no stalls or resets.

---

3.4 POSITION FEEDBACK & MONITORING

SYS-TC-030
- SYS-REQ: 031, 140
- Objective: Verify continuous ADC sampling and correct mapping
- Preconditions: System idle
- Inputs: Flap manually moved across range
- Steps:
  1. Manually sweep flap
  2. Continuously monitor UART/LIN outputs or LEDs
- Expected: Displayed position/feedback updates in sync with real position
- Criteria: No “stuck” or unresponsive position feedback

SYS-TC-031
- SYS-REQ: 032, 033
- Objective: Detected out-of-range ADC triggers system fault
- Preconditions: System powered ON; Flap or sensor deliberately set to fail
- Inputs: Apply sensor open/short
- Steps:
  1. Cause position signal out-of-range
  2. Observe system behavior
- Expected: Fault indicated, motor stopped, error visible to user
- Criteria: See “System safe response”

---

3.5 MOTOR CONTROL BEHAVIOR

SYS-TC-040
- SYS-REQ: 012, 024, 110, 113
- Objective: Start/stop, direction, fault stop
- Preconditions: System idle
- Inputs: Valid movement commands; inject fault
- Steps:
  1. Command position change
  2. Manually cause short/open/load error or force MCU thermal/overcurrent fault
- Expected: Motor drives as commanded, then halts on fault
- Criteria: System executes per spec, stops safely under error.

SYS-TC-041
- SYS-REQ: 021, 022, 023
- Objective: Verify hold/brake mode activation
- Preconditions: Flap at target position
- Inputs: None; observe post-arrival
- Steps:
  1. Command flap movement
  2. System arrives at position
  3. Observe hardware outputs (hold/brake PWM, if visible)
- Expected: Motor enters hold/brake as per system config
- Criteria: No additional/unintended motion.

---

3.6 LED STATUS INDICATION

SYS-TC-050
- SYS-REQ: 050, 052, 073
- Objective: Power/status LED behavior
- Preconditions: System idle, power ON
- Inputs: None
- Steps:
  1. Observe LED state at idle, during movement, on target, on error
- Expected: LED(s) reflect correct visual status: idle, moving, error, fault, and per position
- Criteria: States visible, unambiguous.

SYS-TC-051
- SYS-REQ: 051, 052
- Objective: UART/LIN status/fault feedback
- Preconditions: System powered, connected
- Inputs: Induce errors, valid/invalid position commands
- Steps:
 1. Induce movement, then faults
 2. Monitor status reporting
- Expected: Status frames/messages delivered, correct info for each state; fault events flagged
- Criteria: Diagnostic outputs and communications match system state.

---

3.7 END-TO-END BEHAVIOR

SYS-TC-060
- SYS-REQ: 001, 040, 062, 140
- Objective: User command through to physical flap and visible status
- Preconditions: Flap at mid-position, system idle
- Inputs: UART or LIN command sequence
- Steps:
  1. Command 0 ➔ 3 ➔ 1
  2. Observe each completion (movement, stop, feedback, LEDs)
- Expected: System executes sequence; Each change triggers correct movement and indication
- Criteria: All observable outputs match expected scenario.
