**Document Traceability:** System Requirements (sys-reqs/sys-reqs.txt), Software Architecture (sw-arch/sw-arch.txt)
**Test Plan Owner:** hv-ag-st-git-ds Agent
**Revision:** 1.0

## 1. Purpose & Scope

This SYS.5 document defines the System Qualification Test Specification to verify the HVAC flap actuator system meets all System Requirements through observable, integrated hardware-level behavior on the bench. Test cases are mapped to one or more System Requirement IDs, and only system-level, externally observable behavior is verified. No internal software logic, unit, or integration-level details are included.

## 2. Test Environment & Pre-conditions
- Device under test: Assembled STM32F407G-DISC1 with code as per sw-arch/sw-arch.txt
- Connected hardware: DC motor, position feedback potentiometer, power and green LEDs
- Power supply, signal cables, user UART console interface
- Test setup validated for proper operation before case execution

## 4. Test Cases

### SYS-TC-001: Power-Up Peripheral Initialization
- **Mapped Requirements:** SYS-REQ-020, SYS-REQ-021, SYS-REQ-022, SYS-REQ-017
- **Objective:** Verify all peripherals are initialized, power LED turns on, and the system detects initial flap position; motor remains OFF after power-up.
- **Preconditions:** System unpowered, all wiring correct.
- **Test Inputs:** Apply 5–12V DC power.
- **Test Steps:**
    1. Power on the system.
    2. Observe status and position LEDs, listen for motor activity.
- **Expected Results:**
    - Power LED illuminates immediately.
    - No motor movement on power-up.
    - Position feedback is acquired (verified in next test).
- **Pass/Fail Criteria:** Appearance of correct LED and lack of unintended motor activity.

### SYS-TC-002: Flap Position Command – Position 0
- **Mapped Requirements:** SYS-REQ-002,003,004,006,007
- **Objective:** Ensure that a valid command sets the flap to position 0 correctly, using proper direction, and stops at target.
- **Preconditions:** System idle; position ≠ 0.
- **Test Inputs:** UART command for position 0
- **Test Steps:**
    1. Set initial flap to nonzero (e.g., position 2).
    2. Send command '0' via UART terminal.
    3. Observe motor action and status LED.
- **Expected Results:**
    - Motor drives flap to position 0 only.
    - Motor stops at 0 (no overshoot).
    - Position LED 0 is ON.
- **Pass/Fail Criteria:** Correct stopping and indication; no extra movements.

### SYS-TC-003: Flap Position Command – Position 5
- **Mapped Requirements:** SYS-REQ-002,003,004,006,007
- **Objective:** Ensure that a valid command sets the flap to position 5 using proper direction, stopping at target.
- **Preconditions:** Flap not at position 5; system idle.
- **Test Inputs:** UART command for position 5
- **Test Steps:**
    1. Set initial flap to <5 (e.g., position 3).
    2. Send command '5' via UART.
    3. Observe.
- **Expected Results:**
    - Motor drives to position 5 only. Stops at 5; no overshoot.
    - Correct position LED ON.
- **Pass/Fail Criteria:** Only target movement occurs, stop is precise.

### SYS-TC-004: Invalid UART Command (out of range)
- **Mapped Requirements:** SYS-REQ-004,005,016,026
- **Objective:** System ignores out-of-range numeric commands without motor actuation or error.
- **Preconditions:** Any position; system idle.
- **Test Inputs:** UART command '6', '-1', or '99'.
- **Test Steps:**
    1. Send an out-of-range numeric command.
    2. Observe for any motor or LED change.
- **Expected Results:**
    - System ignores input.
    - No position/motor/LED change.
    - No error message output.
- **Pass/Fail Criteria:** No observable reaction.

### SYS-TC-005: Invalid UART Command (non-numeric)
- **Mapped Requirements:** SYS-REQ-014,016,026
- **Objective:** System ignores non-numeric UART commands.
- **Preconditions:** Any position; system idle.
- **Test Inputs:** UART input 'X', 'abc', '@$#'.
- **Test Steps:**
    1. Send invalid non-numeric string.
    2. Observe system behavior.
- **Expected Results:**
    - System ignores input; remains stable.
    - Motor and LEDs unchanged.
- **Pass/Fail Criteria:** No action or error output occurs.

### SYS-TC-006: ADC Out-of-Range Behavior
- **Mapped Requirements:** SYS-REQ-038,039,011
- **Objective:** System response if potentiometer feedback (ADC) is out-of-bounds.
- **Preconditions:** System running; artificial fault injected (open/short on pot).
- **Test Inputs:** Physically disconnect or short potentiometer during operation.
- **Test Steps:**
    1. Induce ADC out-of-range.
    2. Observe system state, motor, and LEDs.
- **Expected Results:**
    - Motor stops; system idles.
    - Status LEDs show last valid state.
- **Pass/Fail Criteria:** No runaway movement or reset.

### SYS-TC-007: Flap Position Feedback Mapping
- **Mapped Requirements:** SYS-REQ-009,010,011,012
- **Objective:** ADC readings correspond correctly to each of 0-5 logical positions.
- **Preconditions:** System running; access to flap/mechanism.
- **Test Inputs:** Manually rotate flap or adjust pot through full range; monitor ADC/raw value and observed position LED.
- **Test Steps:**
    1. Set flap to each physical position.
    2. Confirm ADC value matches correct position indication.
- **Expected Results:**
    - Each discrete position (0–5) is uniquely detected and indicated.
- **Pass/Fail Criteria:** No overlaps or gaps in mapping.

### SYS-TC-008: Command During Movement / Idle State
- **Mapped Requirements:** SYS-REQ-027,023,025,033
- **Objective:** Verify that system manages state transitions and ignores new commands while busy.
- **Preconditions:** System already moving to a new position due to initial command.
- **Test Inputs:** UART command for new position while previous move is in progress.
- **Test Steps:**
    1. Initiate a move (e.g., command from 1→4).
    2. Send another command (e.g., 2) during movement.
    3. Observe.
- **Expected Results:**
    - Only one command acted on at once.
    - Extra command ignored or safely deferred per requirement.
- **Pass/Fail Criteria:** No misbehavior, crash, or unintended motion.

### SYS-TC-009: LED Status Indication – Position Change
- **Mapped Requirements:** SYS-REQ-019,018,017
- **Objective:** Correct position and status LEDs for all moves and idle states.
- **Preconditions:** System powered; flap not at all positions.
- **Test Inputs:** UART commands for each position (0–5), including power cycling.
- **Test Steps:**
    1. Sequentially command each position with UART.
    2. Observe status LEDs during and after movement.
- **Expected Results:**
    - Only the LED matching current position is ON.
    - Others always OFF.
    - Power LED is always ON when system powered.
- **Pass/Fail Criteria:** LEDs correctly represent real flap position with no ambiguity or lag.

### SYS-TC-010: End-to-End: Command → Motor Actuation → LED Feedback
- **Mapped Requirements:** SYS-REQ-024,028,029,031
- **Objective:** Full system validation: user command to UART results in correct movement and LED change.
- **Preconditions:** System powered, operator present.
- **Test Inputs:** UART commands for positions 0, 3, 5 (minimum).
- **Test Steps:**
    1. Send valid command.
    2. Observe movement and LED.
    3. Repeat for each supported position.
- **Expected Results:**
    - Flap moves only as commanded each time.
    - Motor stops properly at target.
    - Position LED updates each time; no false/missed feedback.
- **Pass/Fail Criteria:** System performs as spec’d, every time across all cases.
