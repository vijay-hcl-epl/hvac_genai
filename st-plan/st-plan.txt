# ASPICE SYS.5 System Qualification Test Specification: HVAC Flap Actuator

## 1. Introduction
This document specifies the System Qualification Test Plan (SYS.5) for the HVAC flap actuator system. The outlined test cases validate the HVAC system's compliance with authoritative IBM DOORS Next system requirements. All test cases are linked to formal SYS-REQ IDs from DOORS (project area: thillaiv Project (Requirements Management)), ensuring traceability for ASPICE Level 3 compliance.

## 2. Test Scope
Tests validate the fully integrated HVAC flap actuator prototype in closed-loop, black-box fashion, focusing on system behavior via external interfaces (UART, ADC, GPIO/LED, PWM/Motor outputs). No internal software inspection is allowed. Unit and module-level tests are outside the scope.

**Test assumptions:**
- Executed on hardware bench setup (STM32F407, L298N, potentiometer, LEDs)
- All hardware is operational

**Interfaces under test:**
UART command input, motor driver outputs, ADC feedback, status LEDs.

## 4. Test Environment Description
- HW: STM32F407 Discovery Board, 12V DC Motor + L298N, rotary potentiometer, status LEDs
- PC with UART terminal for command/test scripts
- Test harness for observing/triggering signals (oscilloscope optional)
- Power supply (bench)

## 7. Pass/Fail Evaluation Criteria
- Every expected hardware/system output, interface status, or indication must strictly match the stepwise expected results.
- Pass: All observations for a given test match expected results with no failure or reset.
- Fail: Any deviation (e.g., system reset, undefined output, motor movement incorrect, wrong LED) constitutes test failure.
