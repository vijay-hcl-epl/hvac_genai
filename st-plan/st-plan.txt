==============================
System Qualification Test Specification (SYS.5)
HVAC Flap Actuator System
==============================

Purpose: This document specifies the system qualification test plan to validate the integrated HVAC flap actuator system for compliance with all functional system requirements (as per sys-reqs/sys-reqs.txt) using real hardware (bench setup). Each test case directly maps to system requirement(s) and assesses only observable system behaviors.

--------------------------------------
Test Case Section: Power-Up & Initialization
--------------------------------------

Test Case ID: SYS-TC-001
Mapped System Requirement ID(s): SYS-REQ-018, SYS-REQ-001
Test Objective: Verify system enters defined idle state and initializes all peripherals correctly on power-up.
Preconditions: Device fully powered down.
Test Inputs: Apply nominal power as per TLE9851QXW datasheet.
Test Steps:
  1. Power on the actuator module.
  2. Observe status LEDs and UART output.
  3. Query initial flap position via UART.
Expected Results:
  - All subsystems initialize without error.
  - Flap is in a defined initial position (idle state).
  - Power and status LEDs indicate normal idle state.
Pass/Fail Criteria: All expected results observed; no errors/faults indicated.

Test Case ID: SYS-TC-002
Mapped System Requirement ID(s): SYS-REQ-010, SYS-REQ-004, SYS-REQ-006
Test Objective: Verify flap position detection and ADC initialization on power-up.
Preconditions: Device powered down, flap manually moved to mid-position.
Test Inputs: Power cycle as above.
Test Steps:
  1. Manually set flap to mid-range.
  2. Power on device.
  3. Query current position via UART.
Expected Results:
  - ADC correctly acquires and reports flap position.
Pass/Fail Criteria: Reported position within +/-2% of actual measured value.

--------------------------------------
Test Case Section: Valid Flap Position Commands
--------------------------------------

Test Case ID: SYS-TC-003
Mapped System Requirement ID(s): SYS-REQ-001, SYS-REQ-013, SYS-REQ-009
Test Objective: System correctly interprets all valid position commands, drives motor, and achieves target without overshoot.
Preconditions: Powered up, idle, flap at any valid position.
Test Inputs: Sequential UART commands for positions 0,1,2,3,4,5.
Test Steps:
  1. Send each supported position command, observe responses.
  2. Monitor flap movement and LED indication.
  3. Wait for movement to stop and query final position.
Expected Results:
  - Flap moves to each commanded position with correct direction.
  - No overshoot beyond target (+/-2% error band).
  - LEDs indicate in-progress/target reached states correctly.
Pass/Fail Criteria: All positions achieved, correct status outputs.

Test Case ID: SYS-TC-004
Mapped System Requirement ID(s): SYS-REQ-003, SYS-REQ-007
Test Objective: Verify flap always stops at the target and motor 'stop' command functions.
Preconditions: Flap in motion by command.
Test Inputs: In-motion UART 'stop' command.
Test Steps:
  1. Start large position change.
  2. During movement, send 'stop'.
  3. Query current position.
Expected Results:
  - Motor stops promptly.
  - Reported position remains stable post-stop.
Pass/Fail Criteria: No further movement after stop, within specified tolerance.

--------------------------------------
Test Case Section: Invalid & Boundary Conditions
--------------------------------------

Test Case ID: SYS-TC-005
Mapped System Requirement ID(s): SYS-REQ-002, SYS-REQ-012, SYS-REQ-015, SYS-REQ-021
Test Objective: Verify system properly ignores/rejects out-of-range and malformed commands and ADC boundary errors.
Preconditions: Powered, idle.
Test Inputs: UART commands outside valid range, malformed UART, forced ADC fault (open/short sensor).
Test Steps:
  1. Send invalid commands and monitor system/UART/LED error indication.
  2. Inject ADC fault and observe.
Expected Results:
  - No motor response to invalid inputs.
  - System reports/indicates errors as specified.
  - No reset/lock-up.
Pass/Fail Criteria: Only error status issued; system remains operational/safe.

Test Case ID: SYS-TC-006
Mapped System Requirement ID(s): SYS-REQ-029, SYS-REQ-030
Test Objective: Validate system’s stability under error and boundary conditions.
Preconditions: Idle, normal environment.
Test Inputs: Inject by quick successive commands, simulate sensor and driver errors.
Test Steps:
  1. Rapidly alternate valid/invalid commands, mix error injections.
  2. Observe error recovery/diagnostics (LEDs/UART).
Expected Results:
  - System remains stable with no lock-up/reset.
  - Error/fault recovery possible by user command or power cycle.
Pass/Fail Criteria: All errors recoverable per requirements; no unsafe state.

--------------------------------------
Test Case Section: Position Feedback & Monitoring
--------------------------------------

Test Case ID: SYS-TC-007
Mapped System Requirement ID(s): SYS-REQ-011, SYS-REQ-012
Test Objective: Verify correct mapping and acquisition of flap position.
Preconditions: Idle; flap at known positions.
Test Inputs: Physically move flap to several measured positions.
Test Steps:
  1. Move flap manually to defined stops (min, mid, max, random).
  2. Query position via UART after each.
Expected Results:
  - Reported positions match physical positions within tolerance.
Pass/Fail Criteria: Δ position error ≤2%; correct reporting for all test points.

Test Case ID: SYS-TC-008
Mapped System Requirement ID(s): SYS-REQ-004, SYS-REQ-010
Test Objective: Verify continuous monitoring and update of flap position.
Preconditions: Active/idle states.
Test Inputs: Mechanically disturb flap during idle and movement.
Test Steps:
  1. Nudge flap off target during idle and in-motion.
Expected Results:
  - System detects displacement and updates status per requirement.
Pass/Fail Criteria: Displacement always detected; position status consistently updated.

--------------------------------------
Test Case Section: Motor Control Behavior
--------------------------------------

Test Case ID: SYS-TC-009
Mapped System Requirement ID(s): SYS-REQ-006, SYS-REQ-008, SYS-REQ-009
Test Objective: Validate correct motor start/stop, direction, and overcurrent/stall protection.
Preconditions: Idle, MCU at nominal supply.
Test Inputs: Position commands, power interruptions, artificial stall (mechanical impedance).
Test Steps:
  1. Command position change; observe motor start and direction.
  2. Introduce stall; monitor current/temperature and system reaction.
Expected Results:
  - Motor drives only as commanded, stops at target, and is protected from fault.
Pass/Fail Criteria: No damage/failure; all protections verified.

Test Case ID: SYS-TC-010
Mapped System Requirement ID(s): SYS-REQ-007, SYS-REQ-030
Test Objective: Confirm motor does not move unintentionally during forbidden conditions (faults, idle, or errors).
Preconditions: Error/fault induced states, or no command.
Test Inputs: Induce motor fault/disable, inject unrelated UART noise.
Test Steps:
  1. Induce protected fault; observe behavior.
  2. Await any motor actuation.
Expected Results:
  - Motor remains stopped under all errors.
Pass/Fail Criteria: No movement occurs when blocked by protection/logic.

--------------------------------------
Test Case Section: LED Status Indication
--------------------------------------

Test Case ID: SYS-TC-011
Mapped System Requirement ID(s): SYS-REQ-016, SYS-REQ-017
Test Objective: Verify correct status LED behavior for operational, error, and fault status.
Preconditions: Idle, errors meaningful.
Test Inputs: Cause operational transitions, inject error/fault.
Test Steps:
  1. Progress system through normal → error → normal using commands and fault injection.
  2. Observe status LEDs throughout sequence.
Expected Results:
  - Power and status LEDs reflect state changes visibly/clearly.
Pass/Fail Criteria: LED patterns/indications always match state per specification.

Test Case ID: SYS-TC-012
Mapped System Requirement ID(s): SYS-REQ-016, SYS-REQ-014
Test Objective: Validate LEDs indicate target achieved, movement in progress, and error situations distinctly.
Preconditions: Normal operation.
Test Inputs: Command target, move flap, cause error.
Test Steps:
  1. Send command, observe LED during movement.
  2. Observe LED at target and with error.
Expected Results:
  - Unique and correct patterns for each status.
Pass/Fail Criteria: LED output always correctly reflects actual system status.

--------------------------------------
Test Case Section: End-to-End Behavior
--------------------------------------

Test Case ID: SYS-TC-013
Mapped System Requirement ID(s): SYS-REQ-001, SYS-REQ-004, SYS-REQ-013, SYS-REQ-016
Test Objective: Demonstrate system-level sequence from user input through actuation and feedback to status indication.
Preconditions: Idle.
Test Inputs: UART position command.
Test Steps:
  1. Command new position.
  2. Observe flap, feedback reporting, status LED change.
Expected Results:
  - Flap actuates, achieves requested position, LED and feedback update correctly.
Pass/Fail Criteria: Each observable action in chain is verified with end-to-end trace; all linked requirements met.
