SOFTWARE REQUIREMENTS SPECIFICATION (SRS)
=========================================
(From agent Hv Ag Softreq1)

1.0 Scope & Responsibility
- Control DC-motor driven flap on STM32F407G-DISC1
- Receive UART command, drive PWM/GPIO, monitor ADC, update LEDs
- No architecture/execution assumptions

2.0 Software Functional Requirements
- UART commands parsed as numeric (0-5), validated, set target
- Internal state updated on valid
- No UART response on invalid
- Compare ADC-derived current vs target
- Command motor, update LEDs, keep at last valid until further command
- Stop motor on reaching target or out-of-bounds
- Static mapping of ADC->position (configurable)

3.0 Interfaces
- UART (input), ADC (feedback), GPIO/PWM for motor/LEDs

4.0 Behavioral
- Startup: init all peripherals, ensure LEDs/motor off/known
- Idle: monitor UART, act on valid
- Always evaluate target/current; on match, stop motor, update LED

5.0 Data & Config
- ADC mapping (array of min/max for each position), all in SW config/static
- State: current/target/logical pos, system variables

6.0 Error Handling
- Ignore out-of-range cmd, stop on invalid feedback
- Never assert, no runtime fault recovery

7.0 Performance
- Responsive to human command, timely ADC polling

8.0 Resource
- No unbounded loops or malloc, all logic is deterministic

9.0 Testability
- Full manual/scripted test over UART, all outputs observable
