1.0 System Overview
-------------------
The HVAC flap actuator system provides automated positioning control of an air flap for a vehicle (prototype context), using a DC motor, position feedback via a potentiometer, and a basic user interface through UART commands and LED indicators. The system is driven by a microcontroller and interacts locally with no networked vehicle communication.

2.0 Flap Position Control
-------------------------
SYS-REQ-001: The system SHALL provide the capability to move the HVAC flap to any of a fixed set of discrete target positions as commanded by the user via UART.
SYS-REQ-002: The system SHALL stop the motor when the flap reaches the commanded target position.
SYS-REQ-003: The system SHALL ignore commands to move to positions outside the defined valid range.
[Implied] SYS-REQ-004: The system SHALL ensure only one position movement takes place at a time.

3.0 Motor Control
------------------
SYS-REQ-005: The system SHALL command the motor to rotate clockwise or anti-clockwise to achieve the requested flap position.
SYS-REQ-006: The system SHALL switch the motor off when the flap is at the commanded position or when an invalid input condition is detected (such as an out-of-range ADC value).
SYS-REQ-007: The system SHALL use dedicated GPIO and PWM outputs for motor direction and speed control.
[Implied] SYS-REQ-008: The system SHALL NOT perform any homing sequence at startup for this prototype.

4.0 Position Feedback Acquisition & Processing
---------------------------------------------
SYS-REQ-009: The system SHALL acquire the current flap position using the ADC-connected potentiometer.
SYS-REQ-010: The system SHALL map ADC values to the discrete logical flap positions based on pre-defined software configuration.
SYS-REQ-011: The system SHALL safely disable motor drive if ADC readings fall outside all defined ranges for valid positions.

5.0 User Command Interface
--------------------------
SYS-REQ-012: The system SHALL accept target position commands as numeric values via UART.
SYS-REQ-013: The system SHALL NOT acknowledge or respond to invalid, malformed, or out-of-range commands.

6.0 Status Indication
----------------------
SYS-REQ-014: The system SHALL activate a dedicated LED to indicate system power-on.
SYS-REQ-015: The system SHALL use up to one green LED at a time to indicate the current logical flap position.
SYS-REQ-016: The system SHALL update the LEDs to reflect status changes within a perceptibly short time after change of state.

7.0 System Behavior (power-up, idle, normal, target reached, invalid input)
----------------------------------
SYS-REQ-017: On power-up, the system SHALL initialize peripherals (ADC, UART, GPIO, PWM), ensure the motor is off, acquire the initial flap position, and set status LEDs to match current state.
SYS-REQ-018: In idle state, the system SHALL wait for valid user commands and maintain the current state of the flap and position LED.
SYS-REQ-019: While moving the flap, the system SHALL monitor position and stop when the target is reached.
SYS-REQ-020: If a position command is received matching the current position, the system SHALL NOT move the motor.
SYS-REQ-021: On receiving invalid input (e.g., invalid UART command), the system SHALL ignore it and take no further action.

8.0 Interfaces (UART, motor driver, ADC, LEDs)
---------------------------------------------
SYS-REQ-022: The system SHALL use UART for receiving user commands only.
SYS-REQ-023: The system SHALL use an ADC channel for potentiometer-based flap position feedback.
SYS-REQ-024: The system SHALL use GPIO outputs for driving the motor driver and indicating position/power LEDs.
SYS-REQ-025: The system SHALL use PWM, as generated by a timer peripheral, to control motor enable/speed.

9.0 Constraints & Assumptions
-----------------------------
SYS-REQ-026: The system SHALL operate with a single flap, a single DC motor, and a single remote command source at any given instant.
SYS-REQ-027: Calibration values for ADC-to-position mapping SHALL be fixed at compile-time and not reconfigurable at runtime.
[Implied] SYS-REQ-028: The system SHALL assume correct operation of all connected hardware for normal behavior.
[Implied] SYS-REQ-029: No dynamic allocation or advanced diagnostics logic is required for this prototype.

10.0 Non-Functional Requirements
-------------------------------
10.1 Responsiveness
SYS-REQ-030: The system SHALL process UART commands and update physical outputs with latency that is perceptibly short to a human user.
10.2 Error Handling & Edge Cases
SYS-REQ-031: The system SHALL safely stop the motor if any critical input reading (e.g., ADC) is out of expected range.
10.3 Resource Constraints
SYS-REQ-032: The system SHALL function within the resource limits of the STM32F407G-DISC1 platform.
10.4 Maintainability & Modularity
SYS-REQ-033: The system specification SHALL be organized in a way that supports independent implementation of command handling, position acquisition, motor driving, and status indication.
10.5 Testability
SYS-REQ-034: The system SHALL allow for functional testing using only UART input, visible LEDs, and direct observation of motor/flap motion.

Architecture-Relevant Considerations Derived from System Requirements
===================================================================
- Concurrency: The system does not require true concurrent processing for core functions; UART command handling, ADC acquisition, and output control can be performed sequentially without race conditions.
- Interaction Complexity: The interface logic is simple, involving direct and local signal handling without protocol handshaking or timeouts.
- Control Complexity: System control flow is state-driven and responds to user input and feedback in a straightforward sequence. Unusual edge cases (e.g., out-of-range feedback) are handled by stopping actuation.
- Expandability: Although limited for this prototype, the requirements are organized to allow future expansion (e.g., more positions, additional safety logic, richer error status) by extending command/feedback ranges or interface logic.
